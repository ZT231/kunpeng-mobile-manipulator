# 项目完整流程模拟（A 档终态 · 端到边到云）

> 范围锁定：仅 A 档（8 项纯软件 0 元功能）。不买激光雷达、不买深度相机，不做 B/C/D 档。
> 目的：在脑子里把"项目做完后到底能干啥、面试能讲啥"跑通一遍，且**诚实不夸大**。

## 〇、一句话定位
"从芯片、PCB、实时控制到边缘 IoT 全栈自研的移动操作机器人"——A 档完成后，它是一个
**移动操作（工作台范围内）、多视角 2D 视觉 + 语音 + 云端大模型 + 可观测 IoT** 的操作演示平台。

## 一、端到端协同架构（三层 + 可观测）

| 层 | 硬件 | 在本项目里干什么 |
|---|---|---|
| **端（语音）** | ESP32-S3 核心板 + INMP441 + MAX98357A | 唤醒词检测、麦克风采集、扬声器播报、WiFi 上云 |
| **边 / 云（编排）** | KunPeng Pro（openEuler aarch64） | 双摄像头视觉追踪、大模型意图理解、IoT 中枢、任务编排 |
| **执行** | 双 STM32F407（底盘 + 机械臂） | 里程计/对准 + 六轴逆解，经串口/CAN 受 KunPeng 指挥 |
| **可观测** | EMQX + eKuiper + InfluxDB + Grafana | 设备遥测→规则→时序库→看板，全程可监控 |

## 二、一个完整演示剧本（人对机器人说一句话，全流程怎么走）

**场景**：小Z 在桌前，机器人停在工作台前（A 档不自主导航，在**工作台范围内**操作）。

1. **语音唤醒（端）**：INMP441 采集环境声 → ESP32-S3 跑 WakeNet 检测"小鲲" → 唤醒后 ASR 转文本"帮我把红色杯子拿过来" → 经 WebSocket/MQTT 发 KunPeng。
2. **意图理解（边·云）**：KunPeng 收到文本 → 调云端大模型 → 解析为结构化指令 `{action:"pick", target:"red_cup"}` → 下发视觉任务。
3. **全局找目标（边·视觉）**：全局视角 GF100 取流 → 颜色追踪找红色 → 算出杯子在画面中的方位（左/右/上/下） → 给机械臂指"对准方向"。
4. **眼在手伺服（边·视觉 + 执行）**：机械臂移到杯子上方 → 眼在手 GF100 近距离追踪杯子质心 → 闭环微调对准（2D 视觉伺服） → 发"对准完成"信号。
5. **执行抓取（执行）**：KunPeng 发"抓取" → STM32F407(机械臂) 逆解驱动舵机 → 夹爪闭合。
6. **语音反馈（端）**：ESP32-S3 播报"已帮你拿到红色杯子"。
7. **全程可观测（IoT）**：质心坐标、任务状态、各设备心跳 → MQTT → EMQX → eKuiper 规则 → InfluxDB → Grafana 实时曲线+面板。
8. **场景理解（边·云）**：定时抓帧发大模型"描述当前画面" → GUI/看板显示，支撑"自然对话/文本聊天"。

## 三、A 档完成后，你能演示 / 面试能讲的东西

- **双视角 2D 视觉**：颜色/质心/KCF 追踪，实时框选 + 轨迹 + 方向提示
- **语音交互闭环**：唤醒 → 识别 → 执行 → 播报（端侧 ESP32-S3 完成）
- **云端大模型驱动**：自然语言指令 → 结构化动作；场景描述 / 对话
- **端-边-云协同**：ESP32 语音、STM32 执行、KunPeng 编排，三层贯通
- **IoT 可观测**：Grafana 看板看设备状态/轨迹，体现"工程化运维思维"
- **自研硬核**：PCB 自画、BOM 自核、串口/CAN 协议自定、IoT 栈自搭

## 四、诚实边界（面试必说，别吹）

- ❌ 不自主导航 / 建图（无雷达，B 档才做）
- ❌ 不 3D 抓取 / 点云（无深度相机，C 档才做）
- ❌ 不本地深度学习自动驾驶（无 GPU/NPU，推理走云端）
- ✅ 它是"工作台范围内移动操作（底盘对准 + 眼在手 2D 视觉抓取）+ 语音 + 大模型 + 可观测"，**不是全自主跨场景导航机器人**
- 差异化在自研深度（PCB / 协议 / IoT），不在功能格数

## 五、升级路线（若日后扩展）

- **B 档 + 雷达** → 自主导航到指定位置再操作
- **C 档 + 深度相机** → 真 3D 抓取、避障、三维建图

## 六、一句话给面试官

> "我这个不是调包套件，是从芯片、PCB、实时控制到边缘 IoT 全栈自研的移动操作机器人。
> A 档阶段它能在工作台范围内用双视角 2D 视觉 + 语音 + 云端大模型完成抓取演示，
> 并通过 IoT 看板做到全程可观测；导航和 3D 抓取是明确的二期规划，我清楚每一层边界。"
