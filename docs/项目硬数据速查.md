## 9 串口与 Flask 接口坑（全部踩过，细节见 `2026-11-12.md`）

### 9.1 一个 5000 只能有一个 Flask

重起前不 `pkill -f "web_control.py"` ⇒ 新进程打印 `Address already in use` 就退出，**服务还是旧的**。典型误判：旧进程没带 `--eye-in-hand`，`/api/ik/eye/solve` 报"未启用"，而 `PING`/`JOINT` 这些老接口照常能用 ⇒ 以为新代码已生效。

⇒ 每次改完必须**先杀再起**，并用启动 banner 的「眼在手：已启用（实测数据）」+ `ss -ltnp | grep 5000` 无残留确认。

### 9.2 串口掉线三形态，报错文案本身就是判据

| 文案 | 含义 |
|---|---|
| `600 ms 内未收到任何字节` | 端口开成功、`port_replaced()` 没命中（节点没换）、读线程活、`write()` 没报错 ⇒ **字节已进 CH341，只缺回程**。多半是丢帧，原样重发即恢复 |
| `串口设备节点已重建或消失` | `port_replaced()` 命中（真重枚举） |
| `串口读取线程异常退出（no data）` | `read()` 抛异常（CH341 被 USB 复位） |

⚠️ `_dev_id` 含 `st_ctime`，**udev 重新 chmod 也会刷 ctime** ⇒ ctime 变化不能当重枚举证据，只有 `port_replaced()` 命中才算。

**丢帧根因与加固（11-12 15:20）**：`SerialHost._rx_loop` 只在 `\r`/`\n` 切行、且要求**整行**以 `$` 开头 ⇒ 前面混进一段没有换行的噪声/printf 尾巴，下一帧就被整条丢弃；`line` 无长度上限。已改：`_RX_LINE_MAX=512` + 见 `$` 即 `line = bytearray(ch)` 重同步（协议载荷不含 `$`，不会切坏正常帧）。验证方式：把磁盘上的真实函数源码按缩进切出来 `exec` 成独立函数，喂假字节流 **10/10 通过**（噪声前缀/超长行/`$` 夹在噪声里/截断帧/二进制噪声/只有 `\n`/裸文本行/空输入）。⚠️ `TcpHost`(:454) 与 `TcpServerHost`(:569) 同写法**未改**（当前走 USB 串口用不到）。

### 9.3 CH341 接线铁律：只接 3 根，5V 必须断开

① CH341 模块的 5V 针≈USB VBUS 直通，而 STM32 已从扩展坞 Type-C 取 5V ⇒ 两针一接＝**用开发板把两个 host 口的 VBUS 短接**＝倒灌；带回灌保护的 host 会直接关端口 —— **这就是 `usb usb5-port1: disabled by hub (EMI?)` 最可能的真因**（11-12 实测两次、间隔 **1079 s**、**全程无 `over-current`** ⇒ 不是过流保护）。
② GND 不能省，否则无共地、串口全乱码。
③ 断开后 CH341 的 GND 成唯一回流路径 ⇒ **舵机(−)/STM32 地/CH341 地必须在电源端子星型汇合**，绝不让 17A 走 28AWG 杜邦线。
④ PA9/PA10 是 FT 引脚 ⇒ MCU 未上电时会被 5V 经保护二极管"寄生供电" ⇒ **先插 Type-C 再连串口，断电反过来**；模块有 3.3V 跳线就拨 3.3V。

**掉线后果**：`ttyUSB0` ↔ `ttyUSB1` **来回翻号**（CH341 无序列号 `SerialNumber=0`），旧 fd 静默死 ⇒ 命令一律写 `/dev/serial/by-id/usb-1a86_USB_Serial-if00-port0`（**名字不变、指向会变，掉线必须重开**）。⚠️ 同一电涌会带停 STM32 ⇒ `Arm_Init()` 开环直写初始位、臂**自己甩回折叠姿态**（这是「复位过」的唯一铁证）。

**接地已确认合格（11-12 实拍 PCA9685）**：舵机红黑粗线直接进模块绿色端子 V+/GND，回路全程不经过 STM32；实测「关舵机电源 STM32 照常 / 关 STM32 舵机仍有电」。⚠️ 只排除「舵机电流穿 CH341 地」，**不等于排除 CH341 的 5V 倒灌**（那是第三路电源）。

### 9.4 判「STM32 死了」还是「只有 CH341 死了」

`POST /api/close` 后裸开串口发 `$LOG,1*CK`，5 s 内每 3 s 一行 `STATE n | PULSE ...` = 活着；反复打 `Robot arm ready.` = 重启循环；`PCA9685 init failed` = 卡 `Error_Handler`（I2C 老坑）；全静默 = 没上电或 TX/RX 断。`LOG` 默认 0（`uart_protocol.c:46`），不主动开不会有输出。

🔴 **「臂不动」只证「没复位过」，不证「STM32 在跑」**：舵机独立供电 + PCA9685 持续输出最后脉宽 ⇒ STM32 **断电**或卡 `Error_Handler` 时臂照样纹丝不动。只有反方向成立：**臂自己甩回折叠初始位 = `Arm_Init()` 跑过 = 确实复位过**。⇒ 判 MCU 死活不能看臂，要看板载电源 LED / 裸串口上电 banner。

### 10.3 重力下垂外推与安全闸门

- 成因：开环稳态误差（力矩在边界），**非**结构柔性、**非**齿隙（0.75°）。C 姿态末端位移 `dx +0.10 / dy −0.95 / dz −3.88 cm`。
