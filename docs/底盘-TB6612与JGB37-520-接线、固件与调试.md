### 2.2 四路编码器（每个定时器只有一路正交接口）


| 轮位   | 6P 座针 C1（A 相） | 6P 座针 C2（B 相） | 定时器  | AF  | 说明                                                                       |
| ---- | ------------- | ------------- | ---- | --- | ------------------------------------------------------------------------ |
| A 左前 | **PB4**（CH1）  | **PB5**（CH2）  | TIM3 | AF2 | 与 W25Q16 的 MISO/MOSI 共用，CS (PB0) 已拉高；**PB4 只在调试口 / NRF 座、不在主排针**（见第 4 节） |
| B 右前 | **PA5**（CH1）  | **PB3**（CH2）  | TIM2 | AF1 | PA5 空闲；PB3=W25Q16 CLK 兼 NRF SCK，CS (PB0) 已拉高                             |
| C 左后 | **PC6**（CH1）  | **PC7**（CH2）  | TIM8 | AF3 | SDIO\_D6/D7，4 位 SD 不用                                                    |
| D 右后 | **PE9**（CH1）  | **PE11**（CH2） | TIM1 | AF1 | 与 TFT FSMC 排座共用，不插屏                                                      |

编码器电源：由 TB6612 板 MOTOR 座 6P 的 `3.3V` 针提供（板载稳压 3.3V 输出），`GND` 与 STM32 共地。

编码器输出 **3.3V 方波**（3.3V 供电）：PB3/PB4/PB5 与 W25Q16 同为 3.3V 电平，直接接无过压；PC6/PC7/PE9/PE11 亦为 3.3V，无需 FT / 钳位。前提是不插 NRF、不开 SPI1、FLASH CS (PB0) 常高。

✅ **PB3/PB4/PB5 与 W25Q16 共用但同为 3.3V 电平**：编码器由 MOTOR 座 3.3V 供电，A/B 输出 3.3V，与 W25Q16 电平兼容，无需拆片或加钳位。唯一要求是 FLASH CS (PB0) 常高（固件已配成推挽输出高）防止 FLASH 被选中、MISO (PB4) 被抢。PB0 才是 W25Q16 的 CS，不是编码器，接线时不要把它接到 TB6612 或编码器。


**不要**给编码器再外接 5V —— MOTOR 座 6P 的 `3.3V` 针已给编码器供电，外接 5V 会怼到 3.3V，倒灌。

### 2.3 为什么这样选脚（被否掉的备选）


| 备选写法                              | 为什么不采用                                                                       | 实际采用                                                     |
| --------------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------- |
| PWM：PB6\~PB9                      | PB6/PB7/PB8 是 NRF24L01 排座的 CE/CS/IRQ（本板无 24C02），整组被 NRF 排座占用                 | **PD12\~PD15**（TIM4 四通道；不插 TFT 时可用）                      |
| DIR 模块 2：PC10\~PC13               | PC10\~PC12 是 SDIO\_D2/D3/CK，PC13 属备份域弱驱动且部分板带 LED；驱动 TB6612 会与 SD 卡 / LED 冲突 | **PB12\~PB15**（TFT 触摸 SPI2 排座，不插屏）                       |
| DIR 模块 2：PA4\~PA7                 | PA5 要留给编码器 B（TIM2\_CH1）；PA6/PA7 是板载 LED D2/D3，整组占用会破坏编码器 B、点亮 LED            | **PB12\~PB15**                                           |
| STBY：PB2                          | PB2 是 **BOOT1** strap，部分核心板带下拉 / 跳线帽，不适合当普通输出                                | **PE8**（TFT FSMC 排座，不插屏）                                 |
| 编码器 B：PA15/PB3                    | PA15 是 JTAG TDI（紧邻 SWD 的 PA13/PA14，SWD 后释放）；PB3 是 W25Q16 CLK 兼 NRF SCK       | **PA5/PB3**（PA5 纯空闲、远离调试区；PB3 复用 W25Q16 CLK，CS (PB0) 常高） |
| 编码器：TIM3 CH1\~CH4 + TIM8 CH1\~CH4 | **不成立**：F4 每个定时器只有一个正交编码器接口，固定占 CH1/CH2（TI1/TI2）；CH3/CH4 不参与解码，这样接只能得到 2 路   | **TIM3 + TIM2 + TIM8 + TIM1 各一路**                        |

这条不是「换脚方便」，是硅片结构决定的：RM0090 的编码器模式只把 TI1/TI2送进正交解码器，CH3/CH4 是独立的输入捕获 / 输出比较通道，不走计数器方向逻辑。

* **不要**把驱动板自带的 `5V` / `3.3V` 输出脚接到 STM32 的 3.3V 排针：

  两边都是「源」，会倒灌。驱动板的 5V/3.3V 输出可以空着，或只给编码器供电（先量电平）。

* 每块 TB6612 的 `VM-GND` 就近并 **100µF/25V 电解 + 0.1µF 陶瓷**；电解负极对 GND。

  四个电机同时换向时，母线会被拽出尖峰，这两个电容是给尖峰兜底的。

* 11.2\~12V 母线先串 **15A 保险**。四轮同时堵转 4×2.3A≈9.2A，15A 是「不误断但能保命」的档位。

* 台架第一次只带底盘，降压限流 **3A**；整车联调再按 8A 评估（舵机堵转叠加会更高）。

### 3.2 驱动板实物结构（6P 电机座型，每块 2 个座）

本文称「板 1 / 板 2」（`chs_tb6612.h` 注释里叫「模块 1 / 模块 2」，同义）。每块驱动板有 **2 个 6P 电机座**（丝印 `MOTOR-A` / `MOTOR-B`），一个座接一个电机；

**注意接口不同**：驱动板电机座是 **XH2.54 6P**（官方参数明确），电机线是 **PH2.0 6P**，

插不进去 —— 需一根 **PH2.0 母 → XH2.54 公** 的 6P 转接线（双头同向、6 针一一对应），不要剪线改焊。

每座 6 针（官方《接线方式》，**按 pin1 编号**；两个座的 pin1 物理方向相反，见下）：


| 针位 | 丝印     | 含义                   | 板内连到                             |
| -- | ------ | -------------------- | -------------------------------- |
| 1  | `M1`   | 电机绕组 +               | TB6612 `AO1`（A 座）/ `BO1`（B 座）    |
| 2  | `GND`  | 编码器地                 | 板 GND（与 STM32 共地）                |
| 3  | `C1`   | 编码器 **A 相**          | 引出针 `E1A`（A 座）/ `E2A`（B 座）       |
| 4  | `C2`   | 编码器 **B 相**          | 引出针 `E1B`（A 座）/ `E2B`（B 座）       |
| 5  | `3.3V` | 编码器电源**输出（板载 3.3V）** | **不要外接 5V**；先量电压确认，对 GND 应读 3.3V |
| 6  | `M2`   | 电机绕组 −               | TB6612 `AO2` / `BO2`             |

🔴 **两个 6P 座是镜像安装的，pin1 方向相反**（实物丝印实测）：`MOTOR-B` 从左往右 = `BO1` `GND` `E2A` `E2B` `3.3V` `BO2`（**pin1 在最左**）；`MOTOR-A` 从左往右 = `AO2` `GND` `E1A` `E1B` `3.3V` `AO1`（**pin1 在最右**）。所以插电机线时**只认丝印文字，不要按「从左数第 1~6 针」**—— 按从左数插，`MOTOR-A` 的 M1/M2 会与 `MOTOR-B` 完全对调（上电就反转），`C1`/`C2` 也会对调（不烧板，但计数方向反）。

🔴 **针序以编码盘实物丝印为准**：官方《接线方式》是 **3=C1（A 相）、4=C2（B 相）**。不同批次的编码盘丝印可能相反，插线前用放大镜看编码器板上的 `C1`/`C2` 标号，**认标号，不要认线的位置或颜色**。C1/C2 接反不烧板，只会让计数方向反 → 改 `EDIR`。


**4 个电机位分配（前后分，与 `chs_tb6612.h` 的轮序完全一致）**：


| 驱动板     | 电机座       | 轮位（代码枚举）  | 车上位置 |
| ------- | --------- | --------- | ---- |
| 板 1（前轴） | `MOTOR-A` | A = 左前 LF | 车头左  |
| 板 1（前轴） | `MOTOR-B` | B = 右前 RF | 车头右  |
| 板 2（后轴） | `MOTOR-A` | C = 左后 LR | 车尾左  |
| 板 2（后轴） | `MOTOR-B` | D = 右后 RR | 车尾右  |

两块板型号相同：**一块管前轴、一块管后轴**。不要按「一块管左、一块管右」分 —— 那样和代码的前后分对不上，`$CAR,RAW` 逐轮测试会错位，调 PID 会一直误判「某轮拖后腿」。


#### 3.2.1 电源输入端子：每块板有两个蓝端子，只接一处

每块板左侧（靠 `MOTOR-B`）和右侧（靠 `MOTOR-A`）各有一个 **2P 蓝色螺钉端子**，丝印不同：


| 端子     | 位置                                 | 实物丝印                       | 针序                | 结论                    |
| ------ | ---------------------------------- | -------------------------- | ----------------- | --------------------- |
| `VIN`  | 右侧，紧邻 `MOTOR-A` 与银色 220µF/25V 电解电容 | `−`（上）/ `+`（下）/ `VIN`      | **上针 = 负，下针 = 正** | **主电源入口（VM）：12V 接这里** |
| `VIN1` | 左侧，紧邻 `MOTOR-B`                    | `VIN1`（上）/ `+` / `VIN2`（下） | 上针 = 正；下针极性未标注    | **未实测前保持悬空**          |

⚠️ **`VIN` 端子是「上负下正」** —— 丝印 `−` 在上针、`+` 在下针。接反会直接烧驱动板，接前用万用表核对。

**为什么只接一处**：一块板只有一颗 TB6612、一个 VM 网络，两个端子在设计上是同一路电源的两个入口（多板级联时一进一出；**是否真的并联，按下面第 1 项通断实测确认**）。接一个就完成供电；两个都接等于把两根线并联，不增加任何电流能力，只多一个接反的机会。

**接线前用通断档确认三件事**（断电、不接电池组）：


1. 右侧 `VIN` 下针（+）↔ 左侧 `VIN1` 上针（+）→ **响** 说明两端子并联，接哪个都一样（仍建议接右侧 `VIN`，丝印最全）

2. 右侧 `VIN` 下针（+）↔ 220µF/25V 电解电容的 `+` 极 → **响** 说明确认是 VM 网络

3. 右侧 `VIN` 上针（−）↔ 控制排针 `GND` 针 → **响** 说明确认是公共地

若第 1 项**不响**，两个端子不是同一网络，**只能接右侧** `VIN`，`VIN1` 永久悬空。

板上丝印以实物为准（本板实物是 `PWMA` / `PWMB`；部分批次印 `PWM1` / `PWM2`）：**A 座配 PWMA、B 座配 PWMB**。


### 3.4 编码器引出针 → STM32（A 相进 CH1，B 相进 CH2）

6P 座的 `C1/C2` 已在板内引到 `E1A/E1B`（A 座）或 `E2A/E2B`（B 座）排针，

从这里再接到 STM32 的定时器：


**先看驱动板这一侧：DRIVER 排针 2 列 × 8 行，从上往下**

| 行 | 左列 | 右列 |
| -- | --- | --- |
| 1 | `PWMA` | `PWMB` |
| 2 | `AIN1` | `BIN1` |
| 3 | `AIN2` | `BIN2` |
| **4** | **`E1A`**（`MOTOR-A` 座的编码器 A 相） | **`E2A`**（`MOTOR-B` 座的编码器 A 相） |
| **5** | **`E1B`**（`MOTOR-A` 座的编码器 B 相） | **`E2B`**（`MOTOR-B` 座的编码器 B 相） |
| 6 | `STBY` | `ADC` |
| 7 | `3V3` | `5V` |
| 8 | `GND` | `GND` |

16 针里**只有 `ADC` / `3V3` / `5V` 三针悬空**；第 8 行两个 `GND` 是板内同一网络，接一根即可。其余 11 针全接（`PWMA` `PWMB` `AIN1` `AIN2` `BIN1` `BIN2` `E1A` `E1B` `E2A` `E2B` `STBY`）。

**8 根编码器线逐根对照（驱动板针 → STM32 引脚 → 排针位置）**

| # | 轮位 | 驱动板针 | 驱动板位置 | STM32 引脚 | 定时器通道 | STM32 板上物理位置 |
| -- | --- | --- | --- | --- | --- | --- |
| 1 | A 左前 | `E1A` | 板 1 · 第 4 行左列 | **PB4** | TIM3_CH1，AF2 | ⚠️ **不在主排针**：NRF24L01 座 MISO 针，或 6 针调试口 `PB4/TRST` 针 |
| 2 | A 左前 | `E1B` | 板 1 · 第 5 行左列 | **PB5** | TIM3_CH2，AF2 | 右排针 `PB5 PB3` 的**左针** |
| 3 | B 右前 | `E2A` | 板 1 · 第 4 行右列 | **PA5** | TIM2_CH1，AF1 | 左排针 `PA4 PA5` 的**右针** |
| 4 | B 右前 | `E2B` | 板 1 · 第 5 行右列 | **PB3** | TIM2_CH2，AF1 | 右排针 `PB5 PB3` 的**右针** |
| 5 | C 左后 | `E1A` | 板 2 · 第 4 行左列 | **PC6** | TIM8_CH1，AF3 | 右排针 `PC6 PD15` 的**左针** |
| 6 | C 左后 | `E1B` | 板 2 · 第 5 行左列 | **PC7** | TIM8_CH2，AF3 | 右排针 `PC8 PC7` 的**右针** |
| 7 | D 右后 | `E2A` | 板 2 · 第 4 行右列 | **PE9** | TIM1_CH1，AF1 | 左排针 `PE9 PE10` 的**左针** |
| 8 | D 右后 | `E2B` | 板 2 · 第 5 行右列 | **PE11** | TIM1_CH2，AF1 | 左排针 `PE11 PE12` 的**左针** |

**读 STM32 排针丝印的规则**：每两个丝印对应两列针，**左字对左针、右字对右针**。例如右排针的 `PB5 PB3`：左针 = `PB5`、右针 = `PB3`，**不是「两个针都叫 PB5/PB3」**。左排针同理：`PA4 PA5` 左针 = `PA4`、右针 = `PA5`。


🔴 **A 相必须进 CH1、B 相必须进 CH2**：定时器编码器模式固定用 CH1/CH2 做 TI1/TI2。两根对调不烧板，但正交计数方向会反 → 改该路 `EDIR` 即可，不用拆线。


* `TIM_ENCODERMODE_TI12`（A/B 两侧都计数）⇒ 4 倍频；11 线 × 90 减速 × 4 = **3960 计数 / 输出轴圈**。

* 编码器供电已在 6P 座内（第 5 针 `3.3V` ＝板载 3.3V **输出**、`GND` ＝公共地），**不用再单独飞线**。

* **编码器 A/B 接反只影响计数方向**：真实前转、计数在减 ⇒ 改 `chassis.h` 的 `EDIR`，别拆线。

* **电机 M1/M2 接反**（`$CAR,RAW` 给正数却把车往后推）⇒ 交换该路 M1/M2 两根线（或改 `WDIR` 符号），

  让「raw + = 车前进」。

上电前万用表确认：`M1-M2` 是电机绕组（十几～几十欧）、`C1-C2` 不是绕组；编码器 `3.3V`（第 5 针）是板载 3.3V **输出**（只接 VM 时对 GND 应约 3.3V），不要再外接 5V。


**备用：若你用的是「裸 TB6612 + 螺钉端子」版（无 6P 座）**—— 电机红 / 白线直接进

`AO1`/`AO2`、`BO1`/`BO2` 螺钉端子；编码器 蓝→3.3V、黑→GND、黄 (A)→CH1、绿 (B)→CH2 单独引线。

接线逻辑与上面完全一致，只是少了 6P 座这一层。

### 3.5 麦轮装法


* 轮毂 6mm 孔配 6mm 金属联轴器，联轴器顶丝必须顶在电机 **D 形轴平面**上，不能顶在圆弧面。

* 80mm 麦轮有左右旋之分：**左前 + 右后** 一组，**右前 + 左后** 另一组。

  从车头看，四个轮的辊子轴线应指向车体中心（X 型）。装反了表现为：

  前进 / 后退正常，但横移变反或原地画圈。

* 轮子装好后先手转一圈，确认不刮底盘、联轴器不偏心；偏心会在 0.3m/s 以上引发整车共振。

## 6. 第一次上电（台架，四轮悬空）

### 6.1 看启动日志

复位后 USART1 应出现：


```
CHS: init OK (2xTB6612, TIM4 20kHz, 4xENC, JGB37-520 1:90)
```

若出现 `CHS: init FAIL (check TIM4 PD12~PD15 / TIM1,2,3,8 encoder pins)`，

说明某个 `HAL_TIM_*_Init/Start` 返回了非 HAL\_OK：先查时钟配置（SYSCLK 是否 168MHz）、

再查这四个定时器是否被 CubeMX 重复初始化。

### 6.2 逐轮点动（不开环跑整车）

发（校验和见第 7 节）：


```
$CAR,RAW,10,0,0,0*09     → 只有 A 左前转，10%
$CAR,STOP*64             → 请求 coast（下一拍 ≤20ms 生效）
$CAR,RAW,0,10,0,0*09     → 只有 B 右前转
$CAR,RAW,0,0,10,0*09     → 只有 C 左后转
$CAR,RAW,0,0,0,10*09     → 只有 D 右后转
```

看三件事：


1. **轮位对不对**（A/B/C/D 与表 2.1 一致）；

2. **物理转向对不对**：给正数时，该轮应把车往前推。本车左右电机镜像安装，右侧 `raw+` 会把车往后推 —— 已用 `WDIR=-1` + `EDIR=+1` 软件补偿（见 6.3 实测记录），不必拆线；若你更愿意改物理接线，就把右侧两轮的 M1/M2 对调，再把 `WDIR` 改回 `+1`、`EDIR` 改回 `-1`；

3. **编码器有没有数**：转的时候发 `$CAR,ENC*34`，对应那一路应明显变化；

   不变化先查该座 `C1`/`C2` 与第 5 针 `3.3V`/`GND` 针。

⚠️ **某轮电机缺失或排线断掉时的行为**：`$CAR,RAW` 完全正常；但 `$CAR,VEL` 会因为缺电机的轮位「目标非零、实测速度为 0」在约 **0.37s** 后触发堵转保护（`[CHS] STALL wheel C/D ... -> FAULT`，四轮 STBY 全关）。这是缺件的必然结果，不是故障。想在这种状态下验证闭环通路，把速度压到堵转阈值以下：`$CAR,VEL,0.05,0,0*14`（`0.05 < CHS_STALL_CMD_MS = 0.08`，四轮都不判堵转）。


### 6.3 自检（可选，但建议做一次）

把 `Core/Inc/chassis.h` 里：


```
#define CHS_SELFTEST_EN   1
```

（`0` = 关闭，`1` = 开启；**当前文件里已经是 1**，自检跑完记得改回 `0` 再重编译。）

重新编译、烧录、复位。四轮悬空，串口先打一行提醒，再逐轮 +20% / −20%，每方向 500ms：


```
[CHS] self-test start: LIFT ALL FOUR WHEELS OFF THE GROUND!
[CHS] dir cfg: EDIR=-1/1/-1/1 WDIR=1/-1/1/-1
[CHS] A(LF) fwd=... rev=... -> OK / CHECK WIRING/ENCODER
...
[CHS] self-test done, 4/4 passed
```

合格判据：`|fwd| > 20`、`|rev| > 20`，且 `fwd` 与 `rev` **符号相反**。

编码器 A/B 反接时 `fwd` 会是负的，但正交解码本身没问题，仍判 `OK`。

**判 `EDIR` 正负不能只看 `fwd` 符号**，要先确定该轮 `raw+` 是不是前进：

- `raw+` = 前进 ⇒ 前进时计数为负 ⇒ `EDIR = -1`
- `raw+` = 后退（镜像安装）⇒ 前进时计数为正 ⇒ `EDIR = +1`，同时该轮 `WDIR` 设 `-1`

两者必须成对，只翻一个会让速度环把「前进」测成负速度、正反馈飞车。

通过后**务必改回 0** 再装车，否则每次上电车都会自己转 4 秒。

**2026-11-25 方向标定全过程（已定案）**

1. **自检（raw ±20%）**：四路 `fwd` 全负、`rev` 全正 —— A −376/+376、B −532/+535、C −554/+567、D −545/+538。符号完全一致 ⇒ 编码器 A/B 相序相对代码约定**系统性**相反，不是个别接线错。
2. **单轮 `$CAR,RAW,30,0,0,0*0B`**：左前 A 朝车头滚 ⇒ A 轮 `raw+` = 前进。
3. **四轮齐发 `$CAR,RAW,30,30,30,30*38`**：**原地打转，左侧（A/C）往前、右侧（B/D）往后** ⇒ 左右电机**镜像安装**，同一 `raw+` 在左右两侧产生相反的车体推力。这是麦轮底盘的正常布局，不是接线错。
4. **定案**：`WDIR` A/C = `+1`、B/D = `−1`；`EDIR` A/C = `−1`、B/D = `+1`。
5. **手工补偿验证**：`$CAR,RAW,30,-30,30,-30*38` 车直行往前。
6. **闭环验证**：重烧后 `$CAR,VEL,0.1,0,0,300*3F`，四轮悬空**全部朝车头滚**，方向链闭环通过。

⚠️ **验证 `WDIR` 必须用 VEL，不能用 RAW**：RAW（`CHS_MODE_OPEN`）在 `CHS_Tick` ⑥ 就 `return`，直接下发 `raw_permille`，不经过 ⑪ 的 `duty × wdir` —— 改完 `WDIR` 再用 RAW 测，车照样原地打转。

⚠️ **改完 `EDIR` 重烧，自检这四行数字不会变**：`CHS_SelfTest` 打印的是 `CHS_TB_ReadDelta()` 的**原始计数**，不乘 `EDIR`。验证 `EDIR` 是否生效要看 `$CAR,WHEEL` 的 `sA~sD`（速度已乘 `EDIR`），或 `$CAR,ODOM`。

🔍 **A 轮首测偏低、复测正常**：首发 376 比 B/C/D 的 532~567 低约 30%，后续几次自检回升到 495~548，与其他轮持平。丢单相会掉一半（~270）而不是 30%，更像 2.4V 下启动偏慢；A 轮 `E1A` 走的是 NRF 座飞线的 `PB4`，标定时仍建议优先复测这一路接触。

如果不通过，按这两条定位：


| 现象                      | 原因                  | 改法                                                         |
| ----------------------- | ------------------- | ---------------------------------------------------------- |
| `fwd ≈ 0`、`rev ≈ 0`     | 电机没转或编码器没接          | 先 `$CAR,RAW,10,...` 看电机；再查该座 `C1`/`C2` 与第 5 针 `3.3V`/`GND` |
| `fwd > 0`、`rev > 0`（同号） | 编码器只接了一相 / C1-C2 短路 | 查 `C1`/`C2` 两针，别接混                                         |
| `fwd < 0`、`rev > 0`（反号） | 编码器 A/B 对调          | `CHS_EDIR_x` 改成 `-1`（只改这一路）                                |
| 电机转但车往后推                | 该轮是镜像安装（本车 B/D 就属于这种） | `WDIR` 设 `-1`、同时 `EDIR` 设 `+1`；或交换该电机红 / 白线                    |

为什么建议（而非必须）`WDIR` 全 +1：四轮都按「raw + = 车前进」接线时，麦轮逆解「四轮同为正 = 前进」最直观。**但本车左右电机是镜像安装的**（`$CAR,RAW,30,30,30,30` 时原地打转），实际定案为 `WDIR = +1/−1/+1/−1`、`EDIR = −1/+1/−1/+1`。

⚠️ `WDIR` 与 `EDIR` 必须**成对翻**：只翻 `WDIR` 不动 `EDIR`，该轮「前进」会被测成负速度，速度环正反馈飞车。想把四轮恢复成全 +1，需要把右侧两轮的 M1/M2 对调（要退 6P 端子针），比软件补偿麻烦。


### 6.4 编码器常数标定（3960 到底对不对）


1. 在 A 轮轮面画一条白线；

2. 发 `$CAR,ENC*34`，记下 A 的原始累计值；

3. 用手**慢慢**把 A 轮正好转一圈（对准白线）；

4. 再发 `$CAR,ENC*34`，差值应约 **3960**（± 几个计数是手转误差）。

差值对不上就改 `chassis.h`：


| 实测 / 圈 | 说明            | 改法                 |
| ------ | ------------- | ------------------ |
| ≈3960  | 11 线，正确       | 不改                 |
| ≈4680  | 13 线          | `CHS_ENC_LINES 13` |
| ≈3600  | 10 线          | `CHS_ENC_LINES 10` |
| ≈1980  | 只测到 2 倍频 / 单相 | 查 A/B 是否有一根没接      |

### 6.5 落地低速测试


1. 12V 限流 3A，车放地上，前方留 2m；

2. `$CAR,VEL,0.1,0,0,1000*0D`（1 秒 0.1m/s），看是否直线、有没有单轮拖后腿；

3. 再试 `$CAR,VEL,0,0.1,0,1000*0D`（右横移）和 `$CAR,VEL,0,0,0.5,1000*09`（逆时针自转）；

4. 方向不对，按这个顺序查：

* **vx 反**：某一轮电机线反了。四轮悬空，`$CAR,RAW` 逐轮看，哪轮反就换哪轮红 / 白；四个都正，vx 才对。

* **vx 对、vy 和 wz 都反**：四个麦轮的辊子对角线装成了另一种（O 型），把四个轮子绕垂直轴转 180°，或在上位机同时取反 vy/wz。

* **只有 wz 反**：先回头确认四轮 vx 是不是真的都往前（单轮装反会被 vx 的平均值掩盖）；四轮都对还反，检查左右轮是不是装错位置。

1. 都对了再上 0.2\~0.3m/s；**不要一上来就 0.45m/s**。

## 7. 协议命令

帧格式不变：`$<payload>*<XOR 两位大写 hex>\r\n`，XOR 覆盖 `$` 与 `*` 之间的全部字节。


| 命令                       | 作用                                                           | 示例（含校验）                  |
| ------------------------ | ------------------------------------------------------------ | ------------------------ |
| `$CAR,VEL,vx,vy,wz[,ms]` | 麦轮逆解速度，m/s、rad/s；500ms 心跳                                    | `$CAR,VEL,0.2,0,0*23`    |
| `$CAR,STOP`              | 请求 coast（下一拍 ≤20ms 生效）                                       | `$CAR,STOP*64`           |
| `$CAR,ODOM`              | 回 `ODOM,x_mm,y_mm,yaw_deg,online`                            | `$CAR,ODOM*75`           |
| `$CAR,RESET`             | 里程计清零                                                        | `$CAR,RESET*29`          |
| `$CAR,RAW,a,b,c,d`       | 开环 ±30%，原始占空比（不乘 WDIR）                                       | `$CAR,RAW,10,0,0,0*09`   |
| `$CAR,WHEEL`             | 回 12 个整数：四轮目标 / 实测 mm/s、占空比‰                                 | `$CAR,WHEEL*2F`          |
| `$CAR,ENC`               | 回四路原始累计计数                                                    | `$CAR,ENC*34`            |
| `$CAR,GAIN,kp,ki,kd`     | 在线改增益，不写 Flash                                               | `$CAR,GAIN,700,900,0*6F` |
| `$CAR,CLRFAULT`          | 清堵转故障；下一拍（≤20ms）由 ChassisTask 重新使能 STBY。无故障时回 `ERR,5`，不会顺手停车 | `$CAR,CLRFAULT*6B`       |

`$STOP` 只停底盘（调 `CHS_Stop` → coast）；无 `$RESUME`。

`$CAR,STOP` 是「请求式」：ChassisTask 在下一拍（≤20ms）才真正把 H 桥 coast。**STOP 后至少等 20ms 再发新的 VEL/RAW**；连续控制时按 10Hz 心跳重发，不要指望 STOP 和 VEL 在同一毫秒内无缝衔接。单轮线速度上限 **0.45m/s**；`vx/vy/wz` 算出的任一轮超限时，四轮**等比缩放**，不逐轮裁剪（裁剪会把合力方向掰歪）。所以上位机给 1.0m/s 不会真的跑 1.0，实际会被压到 0.45m/s 以内。上表示例都已带校验；自己拼新 payload 时用下面脚本算，别手抄错。


```
def frame(payload: str) -> str:
    ck = 0
    for ch in payload:
        ck ^= ord(ch)
    return f"${payload}*{ck:02X}\r\n"

print(frame("CAR,VEL,0.1,0,0,1000"))
print(frame("CAR,RAW,0,10,0,0"))
```

`$CAR,WHEEL` 返回示例（单位 mm/s、‰）：


```
$WHEEL,200,198,430,200,205,425,200,190,440,200,210,420*5D
        tA  sA  dA  tB  sB  dB  ...
```


* `tA/sA` 差得大 → 该轮 PID 没跟上或机械阻力大；

* `dA` 长期顶到 ±1000 → 前馈不够 / 电压低 / 轮子卡；

* 四轮 `s` 都明显低于 `t` → 电池压降或 12V 限流触发。

## 8. PID 调参（先台架，后落地）

默认值（`chassis.h`）：`KP=700, KI=900, KD=0, FF=1800, 死区=70`。

这些只是**起点**，12V/11.2V、车重、轮子阻力不同都要重调。


1. `$CAR,GAIN,0,0,0*61` → 只剩前馈；

2. 发 `$CAR,VEL,0.2,0,0*23`，每 100ms 发 `$CAR,WHEEL*2F`，看 `sA` 是否接近 200mm/s；

* 明显低于 200 → 加大 `FF_GAIN`（1800→2000）；

* 明显高于 200 → 减小；

1. 加 KP：`$CAR,GAIN,300,0,0*62` → `$CAR,GAIN,600,0,0*67` → `$CAR,GAIN,900,0,0*68`，看超调和抖动；

* 轮速在目标附近 ±0.05m/s 抖 → KP 太大；

* 起步软、跟不上 → KP 太小；

1. 加 KI：`$CAR,GAIN,900,300,0*6B` → `$CAR,GAIN,900,600,0*6E` → `$CAR,GAIN,900,900,0*61`，消稳态误差；

* 积分大了会「低速爬行 — 突然窜」，先把 KI 减半；

1. KD 默认 0。编码器 20ms 测速噪声大，加 D 通常只会抖；除非有高频超调才试 20\~50；

2. 调好后把值写回 `CHS_PID_KP/KI/KD`，重新编译；`$CAR,GAIN` 不持久化。

**先调直行，再调横移，最后调自转**。自转时四轮目标相反，任何一轮方向错都会变成

「原地画圈 + 里程计航向飞掉」。

## 9. 故障处理

### 9.1 堵转锁死

现象：车突然停、`$CAR,ODOM` 的 `online=0`、串口打印：


```
[CHS] STALL wheel B: cmd=200 mm/s, spd=3 mm/s -> FAULT
```

处理：


1. 断电 / 架空前检查该轮是否被线束、联轴器、底盘卡住；

2. 手转该轮应顺畅；

3. 确认不是「目标太小 / 静摩擦大」造成的误判（`CHS_STALL_CMD_MS=0.08` 以下不判）；

4. 发 `$CAR,CLRFAULT*6B`；等 ≥20ms 让 ChassisTask 重新拉高 STBY，再重新 `$CAR,VEL`。

5. 连续多次堵转：查 12V 是否掉压、TB6612 是否过热、电机是否进灰。

### 9.2 不动 / 单轮不转


* 单轮不转：`$CAR,RAW,10,0,0,0` 点动；不转 → 查该路 PWM/DIR 线、TB6612 该通道、

  电机 M1/M2；转但 `$CAR,ENC` 不变 → 查编码器 `C1`/`C2`/ 第 5 针 `3.3V`/`GND`。

* 四轮都不转：STBY（PE8）是否为高；12V 是否到 VM；`online` 是否 0。

* 一转向就重启 / 复位：12V 尖峰 / 共地不良，查 100µF、星点地、电池限流。

### 9.3 速度上不去 / 电流大


* 12V 实际掉到 10V 以下 → 电池 / 降压限流；

* 联轴器打滑 → 顶丝没顶到 D 平面；

* 麦轮装反 → 横移阻力大；

* PID `d` 顶满但 `s` 低 → 机械阻力 / 轮子刮底盘。

## 10. 诚实边界


* **实机进度**：4 轮 + 2 块驱动板已全部接线完成，前轴 A/B 已通电转动验证；**四轮自检、整车运动、里程计、PID 尚未验证**。

  Rebuild 0 Error / 0 Warning（正常版 Code=24440，自检版 Code=24996），

  `KP/KI/FF` 是按 12V/110rpm 估的起点，必须按第 8 节实测重调。

* **没有电流环**：TB6612 没有电流反馈脚，代码只能靠「PWM 有、编码器不走」判堵转；

  轮子打滑空转（编码器仍在转）时不会保护，可能持续 2.3A 堵转电流（四轮 9.2A）。

* **TB6612 余量薄**：1.2A 连续 vs 电机 2.3A 停转（四轮 9.2A），任何长时间堵转 / 频繁正反转都要避免；

  台架限流 3A，落地限流按 8A 评估。

* **里程计会漂**：麦轮靠轮速积分，打滑、地面不平、轮径磨损都会累计误差；

  只能做短时相对定位，不能替代激光雷达 / 视觉。

* **实际 dt 会抖**：速度 / 里程计用 HAL tick 实测 dt，不再硬按 20ms；PID 的控制 dt

  夹到 100ms，任务被长时间阻塞时控制会变慢，但不会把速度算翻倍。

  `StartChassisTask` 另有「欠拍不补跑」保护，极端负载下仍应以实测为准。
