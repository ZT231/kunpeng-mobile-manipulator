# 焊接第一时间排查小抄（上电即查 · 电压/电流 → 哪颗料焊反了）

> 用法：焊完一批、上电前/上电后，**先拿万用表量这几个"黄金测试点"**，对照下面的表，10 秒内定位焊反/短路的是哪颗料。和 `焊接检查表与上电测试顺序.md` 配套用——那份是"怎么焊"，这份是"焊完不对劲查哪"。
> 两块板都用 AMS1117-3.3（SOT-223：**Pin1=GND / Pin2=VOUT / Pin3=VIN，散热片 Tab 连 VOUT**）。ESP32 板无 VCAP；STM32 板有 VCAP(C5/C6)。

---

## 〇、黄金测试点 + 正常读数（先记这组数）

| 测试点 | 两块板都有？ | 正常读数 | 怎么测 |
|---|---|---|---|
| 5V 网络（USB-C VBUS / 5V 焊盘） | 都有 | **5.0V ±0.2V** | 黑笔接地，红笔点 5V 测试点 |
| 3.3V 网络（AMS1117 输出脚 / 任意 3.3V 测试点） | 都有 | **3.30V ±0.1V** | 黑笔接地，红笔点 3.3V 测试点 |
| GND（任意地过孔） | 都有 | **0V**（相对自身） | 通断档测与各 GND 相通 |
| VCAP（C5/C6 两端，对 GND） | 仅 STM32 | **≈1.2~1.3V** | 黑笔接地，红笔点 VCAP 焊盘 |
| EN（ESP32 模组使能脚） | 仅 ESP32 | **高电平 ≈3.3V**（上拉） | 量对 GND |
| NRST（STM32 复位脚） | 仅 STM32 | **高电平 ≈3.3V**（上拉） | 量对 GND；按复位键瞬间变 0 |
| BOOT0（STM32） | 仅 STM32 | **低电平 ≈0V**（下拉，从 Flash 启动） | 量对 GND；想 ISP 时人为拉高 |

> 记牢三个锚点：**5V=5.0、3.3V=3.30、VCAP=1.2**。任何偏离从这三角色开始查。

---

## 一、3.3V 读数异常 → 查哪颗料（最高频）

| 你量到的 3.3V | 危险 | 可能焊反/出问题的料 | 怎么确认 + 处理 |
|---|---|---|---|
| **= 0V（完全没输出）** | 【高危】 | ① AMS1117 输入脚(VIN)没吃到 5V → 输入脚焊反/连锡到别脚<br>② AMS1117 VOUT 对 GND 短路（输出电容 22µF/100nF 焊反击穿、下游 MCU/模组短路拉死、VOUT 与 GND 桥连）<br>③ 5V 网络本身没电（见第二节） | 先量 5V 有没有：有 5V 但 3.3V=0 → 查 AMS1117 输入脚电压；输入脚有 5V 但输出 0 → 蜂鸣测 VOUT 对 GND 是否短（短路则查下游/电容）；输入脚无 5V → AMS1117 脚位错或 5V 没连到它。立刻断电再查，别硬上。 |
| **= 5V（等于输入）** | 【致命】 | AMS1117 **VOUT 与 VIN 脚位焊反/桥连**（最典型：芯片转了 180° 焊，或相邻脚连锡），输入直接串到输出 | **立刻断电！** 这会烧下游所有 3.3V 器件（MCU/模组/CH343G）。重焊 AMS1117，确认 Pin1=GND 在左、Tab 连 VOUT。焊前用二极管档确认 Tab 与 VOUT 通、与 VIN 不通（见焊接检查表）。 |
| **≈ 2.1V（偏低不到 3.3）** | 【高危】 | ① **量错点**：把 VCAP(≈1.2V) 或 晶振脚(≈1.6V) 当成 3.3V 量了（最常见！先排除）<br>② AMS1117 输入脚实际没 5V、被某处分压到 ~3.3V（5V 网络经电阻/连锡/漏电分压）→ dropout 不够，输出 = 输入−1.1V ≈ 2.2V<br>③ AMS1117 GND 脚虚焊/悬空 → 基准丢失，输出异常 | 先确认你红笔点的确实是 3.3V 丝印测试点（不是 VCAP）。再量 AMS1117 输入脚电压：若输入只有 ~3.3V → 查 5V 网络为什么被拉低（上游/分压）；若输入有 5V 但输出 2.1V → AMS1117 地脚虚焊或芯片坏，补焊 GND 脚/换料。 |
| **= 4.xV（偏高但不满 5V）** | 【高危】 | AMS1117 部分脚位错（如 GND 脚虚焊导致稳压失效、pass-through 半导通） | 断电查 AMS1117 三脚 + Tab 方向，补焊地脚；仍异常换一颗。 |
| **抖动/纹波大/忽高忽低** | 【中】 | ① 输出电容没焊/虚焊/容值错（要求 ≥10µF，用 22µF 那颗）<br>② 输入电容缺失<br>③ 负载有短路被限流，电压被拉低 | 量输出电容两端是否 3.3V 且稳；补焊/补焊输出 22µF；确认输入 10µF 在位。 |

## 二、5V 读数异常 → 查哪颗料

| 你量到的 5V | 危险 | 可能焊反/出问题的料 | 处理 |
|---|---|---|---|
| **= 0V（没供上）** | 【中】 | ① USB-C 座焊反/虚焊，VBUS 没连到 5V 网络<br>② CC1/CC2 下拉电阻(5.1k)没焊/错值 → 主机不给 VBUS（ESP32 板串口那颗 Type-C）<br>③ 自恢复保险丝断/没焊<br>④ 你插的线根本没供电 | 换根确认好的 USB 线/电源；量 USB-C 座 VBUS 焊盘有没有 5V；查 CC 电阻；跳过大保险丝试（仅排查，勿长期短接）。 |
| **< 5V（如 4.3V）带载更掉** | 【低】 | 供电线/座接触电阻大、线太细、电源带载差 | 换粗线/好电源；确认非板子问题（空载也低才是板子问题）。 |
| **= 5V 但 3.3V 异常** | — | 见第一节 | 转第一节按 3.3V 值查。 |

## 三、VCAP（仅 STM32 板）异常 → 查哪颗料

| 你量到的 VCAP | 危险 | 含义 | 处理 |
|---|---|---|---|
| **≈ 1.2~1.3V** | — | 正常，内核 1.2V 稳压输出 | 没问题，继续。 |
| **= 0V** | 【高危】 | C5/C6（2.2µF）**焊反/击穿短路到地**，或根本没焊（空着时内部稳压仍应有 ~1.2V，所以 0V 多半是短路） | 蜂鸣测 VCAP 对 GND 是否短；短路则查 C5/C6 方向/好坏、焊点桥连。VCAP 短路 → MCU 内核没电 → 必死机不启动。 |
| **= 3.3V** | 【致命】 | VCAP 电容焊反/桥连到 VDD(3.3V) → 内核过压，可能烧 MCU | **立刻断电**，重焊 C5/C6，确认一端接 VCAP 脚、另一端接 GND，不是接 3.3V。 |

## 四、上电电流异常 → 查哪颗料

| 你看到的电流 | 危险 | 含义 | 处理 |
|---|---|---|---|
| **一上电直接爆表/限流触发（>100mA 且 3.3V 被拉低）** | 【致命】 | 某处**硬短路**：VCC-GND 桥连（LDO 输出区、模组底部、MCU 相邻脚、排针相邻脚）、极性电容反接、WS2812B 焊反 | 立刻断电！通断档蜂鸣测 3.3V 网络对 GND：哪段响就是哪段短。优先查 LQFP/模组底部连锡、电容反接。 |
| **电源区单独上电就 >30mA** | 【高危】 | 电源区本身短路：AMS1117 焊反、输出电容短路、LED 限流电阻没焊（LED 直接对地） | 先拔掉核心 IC，只留电源区查。 |
| **裸板待机 < 预期（如 ESP32 板 <5mA、STM32 板 <5mA）** | 【低】 | 可能某个本该通电的器件没供上（虚焊/漏焊），不一定是坏事，但要点灯才能确认活没活 | 继续走点灯流程验证。 |
| **待机正常但一跑程序电流不动/不增** | 【提示】 | MCU 可能没真跑（没进程序/没起振） | 查时钟/BOOT0/程序是否下载成功。 |

## 五、有电但不启动（MCU/模组活着但跑不起来）→ 查哪颗料

**STM32（有 3.3V、VCAP≈1.2V，但 ST-LINK 连不上/不跑）：**
- [ ] **VCAP 没焊** → 内核不稳死机（最常见"有电不跑"）。
- [ ] **晶振没起振**：8MHz 两端负载电容(C16/C17)焊反/容值错(非 20pF C0G)/虚焊 → 用 HSE 跑不起来；万用表量晶振两脚约 1.6V 是常态偏置，≠起振，需示波器看正弦。
- [ ] **BOOT0 悬空/被拉高** → 不进 Flash 用户程序（应从 Flash 启动需 BOOT0=0，即 10k 下拉到地）。
- [ ] **NRST 被拉死**：10k 上拉/100nF 焊反、复位按键常闭 → MCU 一直复位。量 NRST 应是高，按按键瞬间变 0。
- [ ] **1 脚转反 180°** → 全板信号错乱，必重焊。
- [ ] **VDD/VSS 有漏脚没焊/桥连** → 部分电源域没电。

**ESP32（有 3.3V，但电脑不识别/不启动）：**
- [ ] **EN 没上拉** → 模组一直复位不运行（EN 应 ≈3.3V）。
- [ ] **GPIO0 下载时序/电路错**：CH343G 的 DTR→GPIO0、RTS→EN 一键下载电路（含三极管反相）焊错 → 进不了下载模式。
- [ ] **模组虚焊/底部连锡** → 部分电源/信号脚没通。
- [ ] **3.3V 到模组实际不足**（被压降） → 见第一节 2.1V 排查。

## 六、外设专项（有电、核心活了，但外设不干活）

| 现象 | 优先查的料 | 提示 |
|---|---|---|
| WS2812B 第一颗就不亮 | DIN 脚位（以规格书为准，别凭切角）、5V 供、GND 共地、GPIO48 程序、330Ω 串没串 | 焊反 → 不亮且吃电流异常；共地没接 → 完全不响应 |
| 串口(CH343G)电脑不识别 | 驱动装没装、DTR/RTS 电路、USB-C CC 电阻 | 先换根线/换 USB 口排除电脑侧 |
| ST7789 屏不亮 | SPI 接线(CLK/MOSI/CS/DC/RST)、背光供电、3.3V 到没到、初始化程序 | 先确认 3.3V 和背光使能 |
| INMP441/MAX98357A 没声 | I2S 接线(SCK/WS/SD)、5V/3.3V 供电、程序初始化 | 用示波器/逻辑分析仪看 I2S 时钟有没有 |

## 七、反向速查：某颗料焊反了 → 表现是什么

| 如果焊反/焊错的是… | 上电量到的典型现象 | 一眼判断 |
|---|---|---|
| **AMS1117 转 180°（VIN/VOUT 反）** | 3.3V 网络 = 5V（或炸/烫） | 【致命】立刻断电，下游危 |
| **AMS1117 脚位错（GND 悬空等）** | 3.3V 偏高(4.x)或异常 | 重焊三脚+Tab |
| **LED 反接** | 不亮，一般不烧 | 翻过来重焊 |
| **极性电容(电解/钽)反接** | 漏液/发热/短路爆表 | 立刻断电换，反接会炸 |
| **USB-C 座反/虚焊** | 5V=0，板子没电 | 查 VBUS 焊点+CC 电阻 |
| **WS2812B 方向反** | 第一颗不亮、电流异常 | 翻 DIN/DOUT |
| **STM32 / ESP32 模组 1 脚转反** | 全板信号错乱、不启动、可能烫 | 必重焊对齐圆点 |
| **VCAP 电容(C5/C6)短路到地** | VCAP=0、MCU 死机不启动 | 查 C5/C6 |
| **VCAP 电容接到 3.3V** | VCAP=3.3V、可能烧内核 | 【致命】立刻断电 |

---

> 背住这组对应：**3.3V=0→查输入/短路；3.3V=5V→AMS1117 反了快断电；3.3V=2.1V→先确认没量错 VCAP、再看 5V 有没有被分压；VCAP=0→C5/C6 短；VCAP=3.3V→C5/C6 接错快断电；电流爆表→某处硬短先断电源。** 一上电量一下，10 秒定位。
