# 精度目标与硬件升级路径（直面"毫米级"需求）

> 背景：小Z 曾确认"想要精确到毫米级别"，但最新决策（2026-11-02）为**控制成本、复用既有舵机**，机械臂执行器定为 **4× 25kg 数字舵机 + 2× MG996R（均为 PWM 开环舵机）**，放弃原计划的 STS3215 总线舵机升级。本文把现有 PWM 方案的精度天花板算清楚，并保留达到毫米级的三档升级路径（当前均未采用）。**核心结论：PWM 开环舵机在物理上无法达到毫米级，瓶颈是执行器（齿轮回差 + 无位置反馈），不是相机。**

---

## 一、先说人话：精度分两种，别混

> **概念·重复定位精度（大白话）**：机器人把臂末端送到同一个目标点，反复送 10 次，这 10 次落点之间差多少。差得越小越"稳"。
> **规范定义**：Repeatability = 在相同条件下，机械臂末端执行器多次到达同一指令位姿时的离散程度（标准差或最大偏差），单位 mm；由关节编码器/反馈分辨率、齿轮回差、结构刚性决定，与"标不标定"无关。

> **概念·绝对定位精度（大白话）**：目标在真实空间里是 (x,y,z)，机器人认为自己到了 (x,y,z)，实际差多少。这包括了"重复定位准、但整体偏了"的情况。
> **规范定义**：Accuracy = 末端实际位姿与指令位姿之间的系统偏差，单位 mm；取决于运动学建模误差 + 手眼标定残差 + DH 参数误差，可通过标定补偿一部分，但永远有下限。

**一句话**：重复定位是"稳不稳"，绝对精度是"准不准"。毫米级通常指**绝对定位精度 ≤ ±1mm**。

## 二、现有配置的天花板（基于已确认硬件）

已确认事实（见 `硬件清单.md` 第 88 / 254 行，2026-11-02 最新决策）：
- 机械臂 = **六自由度舵机机械臂，执行器 = 4× 25kg 数字舵机（PWM 开环）+ 2× MG996R（PWM 开环），共 6 路标准 PWM（50Hz / 0.5~2.5ms）**
- 相机 = 双 GF100（2.8mm 全局 + 3.6mm 眼在手）；**注：眼在手 GF100-B 暂延后采购，当前阶段 2 验证仅用 GF100-A（全局）单相机**

各环节误差量级（实测经验值）：

| 环节 | 误差量级 | 说明 |
|---|---|---|
| GF100 像素分辨率 | **0.3~0.5 mm/像素**（0.3m 处） | 相机底子够，远在 ±1mm 目标线下 |
| 镜头畸变（标定后） | ~0.5~1mm | 无畸变镜头 + 标定可压到压线 |
| **舵机臂重复定位（PWM 开环）** | **25kg 数字舵机轴 1~3 mm；MG996R 轴 3~5 mm** | 舵机内部自带位置伺服、MCU 无反馈；误差来自齿轮回差 ±1~3°，臂展 20~30cm 时末端累积到 cm 级 |
| **手眼标定残差（新手）** | **5~20 mm** | 标定板采集姿态不够多/均匀时最差 |
| **整体闭环绝对精度** | **≈ cm 级（5~20mm）** | 由最弱环节决定，相机再好也补不上 |

> ⚠️ **结论钉死**：GF100 分辨率已达亚毫米/像素，换更贵的相机**完全弥补不了舵机臂的 cm 级误差**。要毫米级，第一步必须换执行器。

## 三、达到毫米级的硬件升级路径（三档）

> 📌 **当前选定方案（2026-11-02）**：机械臂执行器 = **4× 25kg 数字舵机 + 2× MG996R（PWM 开环）**，下面三档均为**可选升级路径、目前均未采用**。当前演示为 **cm 级**，足够展示系统级能力；毫米级是「以后有钱/有需求再升级」的路线，不是当前承诺。

### 方案 A · 总线舵机升级（低成本，到 1~2mm）★ 可选升级路径（当前未选）★
- **做法**：把 6 路 PWM 开环舵机换成**带磁编码反馈的闭环总线舵机**。实测选型 **Feetech STS3215**（7.4V/19kg.cm、12-bit 磁编码、≈0.088°/LSB、半双工 UART 1Mbps、反馈位置/速度/负载/电压/温度/电流），STM32 通过半双工串口（DIR 脚切收发）下发角度+读回实际位置，形成闭环。驱动需在升级时新增；当前 PWM 方案见 `Core/Src/pca9685.c`。
- **精度**：单关节重复定位由 PWM 开环舵机的 ±1~3°（机械臂末端 cm 级）降至 **±0.3° 以内**，臂展 25cm 时末端约 **1~2mm**。
- **成本**：STS3215 国内零售 **99 元/个**（2026-11-02 飞特官网核实），6 个 ≈ **¥600**；若选更大扭矩款 LDX-227（20kg.cm，约 ¥150~200/个）则 ≈ ¥900~1200。比此前预估（¥900~2100）更低。
- **工程量**：中。需从当前 PWM 舵机驱动（`Core/Src/pca9685.c`）切换到 UART 总线协议 + 位置回读 + 堵转保护；接线须舵机电源与 MCU 逻辑电源**分离**（堵转 2A/颗会拉塌 UART 电平）。
- **适配**：A 档精神不变（仍是舵机臂本体，不换结构），但精度上一个量级。

### 方案 B · 步进/伺服 + 谐波减速（中成本，亚毫米）
- **做法**：每关节用 **42 步进电机 + 谐波减速器（减速比 50~100）+ 编码器闭环**，或交流伺服。彻底告别舵机的回差问题。
- **精度**：单关节角分辨率达角秒级，末端 **<0.5mm**（接近 ±0.2mm）。
- **成本**：六轴套件（含谐波）约 **¥2000~5000**。
- **工程量**：高。需重新设计机械臂结构（电机+谐波尺寸大、重），电机驱动板、闭环控制算法都要重做。
- **适配**：机械臂本体大改，已超出"复用既有项目"的初衷。

### 方案 C · 工业协作臂（高成本，±0.02mm）
- **做法**：直接采购成品协作臂（遨博 i 系列 / 节卡 / 越疆），自带控制器与高精度标定。
- **精度**：标称 **±0.02~0.05mm**。
- **成本**：**¥2 万~8 万**。
- **工程量**：低（开箱即用），但项目"自研硬件"的含金量被稀释——面试官会问"臂是你做的吗"。
- **适配**：仅当你要真做工业级演示、且不在意"臂非自研"时。

## 四、视觉侧必须同步升级（否则仍然到不了毫米）

光换臂不够，视觉也要跟上：

| 升级项 | 为什么 | 成本 |
|---|---|---|
| **全局快门相机**（替代卷帘 GF100） | 消除"果冻"拖影，质心算得准 | OV9281 USB3.0 约 ¥150~300 |
| **深度/结构光相机**（提供真实 3D） | 2D 只能 pseudo-3D（已知高度），真毫米级要真 3D 坐标 | Orbbec Astra S（短距 0.4~2m）或 Gemini 2，¥900~2000 |
| **高精度标定板** | 棋盘格/圆点阵列，多姿态采集把手眼标定残差压到 <1mm | ¥20~50 |
| **手眼标定算法** | Tsai-Lenz / Park-Martin，自动采集 ≥15 组位姿 | 软件，0 元 |

> ⚠️ 注意：Astra Pro 量程 0.6~8m，对**眼在手（eye-in-hand）安装**的近距抓取（0.3~0.5m，机械臂末端到目标的工作距离）是盲区；要短距型号 **Astra S（0.4~2m）** 或 Gemini 2。
>
> 反过来，Astra Pro 官方那套「抓取分拣」是可用的——它是**相机固定在料箱上方 0.8~1.2m 俯视**（eye-to-hand 眼在外），工作距离在量程内。**能不能用取决于装法，不取决于相机本身。** 详见 `硬件清单.md` 4.2 节。

## 五、诚实边界（面试必说，别吹）

1. **当前 PWM 舵机配置 = cm 级演示**，足够展示"系统级能力"（PCB/协议/视觉伺服/IoT 全栈），但**不是毫米级**——这是选型已定的事实，别硬吹。
2. 若日后升级到方案 A（总线舵机），可诚实说"**重复定位做到 1~2mm，绝对精度靠高精度手眼标定压到亚 cm**"——这是真实可达的，但当前没做。
3. 方案 B/C 才能稳定 ±1mm 以内，但工程量/预算跳档。
4. **千万别说"GF100 加个标定就毫米级"**——这是错的，执行器才是天花板。

## 七、决策建议（2026-11-02 最新）

- **当前决策已定**：机械臂用 **4× 25kg 数字舵机 + 2× MG996R（PWM 开环）**，做到 **cm 级系统演示**即可；精力放在"云-边-端全栈 + 自研硬件"的差异化上，不砸钱追毫米级。这是有意为之的成本控制，不是做不到。
- **若日后真要毫米级演示**：从**方案 A（总线舵机，~¥600 起）**起步，性价比最高，且仍保留"臂驱动自研"的含金量；视觉侧补全局快门相机 + Astra S + 标定板（再加 ~¥1200）。
- **方案 B/C 仅在确有工业级需求时考虑**，会显著偏离"复用既有项目、低成本自研"的初衷。

> 本决策与"范围锁死 A 档（不买雷达/深度做导航 3D）"不冲突：A 档管"做什么功能"，本文管"抓取精度到哪"，是独立的一笔可选投资；当前投资级别 = 0（复用既有舵机）。
