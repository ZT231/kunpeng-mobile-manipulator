# 焊接与上电检查（ESP32-S3 / STM32F407）

> 适用对象：
> ① ESP32-S3-WROOM-1 N16R8 自研核心板（35.56×63mm）—— 📋 已回板**待焊**；开发期用成品 ESP32-S3 板（已烧录实机）；
> ② STM32F407VET6 自研核心板（LQFP-100，55×70mm）—— 📋 已回板**待焊**；当前实机用的是成品 F407VET6 开发板；
> ③ 底盘 STM32F407Zx 核心板（LQFP-144）—— 📋 未回板、未焊，焊法同 ②，引脚更多、桥连风险更高。
>
> 本文把「怎么焊」与「焊完不对劲查哪」合成一份：第 1~6 节是焊接流程与每批上电判定，第 7~10 节是上电后的电压/电流速查。
> 核心原则：**先焊电源区 → 单独上电验证 3.3V → 再焊核心 IC（模组/MCU 最后焊）**，分段焊、分段测，烧也只烧便宜的 LDO，不烧几百块的核心。
> 两块板都用 AMS1117-3.3（SOT-223：**Pin1=GND / Pin2=VOUT / Pin3=VIN，散热片 Tab 连 VOUT**）。ESP32 板无 VCAP；STM32 板有 VCAP(C5/C6)。

---

## 1 防翻车三条铁律（焊之前念一遍）

1. **【静电】** 所有 CMOS 芯片（ESP32 模组、STM32、CH343G、WS2812B、MAX98357A、INMP441）都怕静电。焊前先摸一下接地的金属水管/机箱放电，最好戴防静电手环、烙铁接地。ESP32-S3 模组最贵最娇气，**最后焊、别用手直接捏引脚、别在干燥毛衣旁操作**。
2. **【分段】** 绝不一次焊完。每焊完「电源区」就先单独上电测 3.3V，PASS 了再焊下一区。核心模组/MCU 永远最后焊。
3. **【先电流后电压】** 上电前接 USB 电流表或限流电源（先限流 100mA）。先听/看有没有短路大电流、冒烟、烫手，再量电压。**一上电异常立刻断电**，别硬撑。

---

## 2 焊前准备（所有板通用，勾完再开焊）

- [ ] 工具齐：电烙铁（建议 350℃ 以内尖头）、含松香芯焊锡（0.6~0.8mm）、助焊剂、吸锡带/吸锡器、镊子、放大镜或手机微距、万用表（蜂鸣档+电压档）。
- [ ] ESD 防护：防静电手环/接地、烙铁接地、工作台铺防静电垫或干净纸。
- [ ] 调试伙计备好：ST-LINK V2.1（STM32 用）、USB-TTL / CH343 驱动装好（ESP32 用）、USB 电流表或带限流的可调电源。
- [ ] BOM 分料：把每颗料按位号（R1/C2/U3…）摆好，对照 PCB 丝印图（不是封装图），别凭记忆拿料。
- [ ] 上板前先「通断体检」PCB：
  - [ ] 蜂鸣档测 **所有 GND 测试点应连通**（整板地是一张网）。
  - [ ] 蜂鸣档测 **任意 5V 网络 与 3.3V 网络 之间不短**（最怕 5V 灌进 3.3V 烧核心）。
  - [ ] 蜂鸣档测 **任意 VCC 与 GND 之间不短**（空板不应有电源-地短路）。
- [ ] 极性元件先认方向（焊前在桌上摆好，标好 1 脚/正极）：LED、电解/钽电容、USB-C、WS2812B、各芯片的圆点/切角/丝印 1 脚标记。

## 3 ESP32-S3 核心板（35.56×63mm）焊接 + 上电顺序

板子事实（已核对 BOM）：U2=**AMS1117-3.3** 供电，3.3V 去耦 22µF(C2)+10µF/100nF 多颗，符合乐鑫指南；**无 VCAP、无 RT9193**；CH343G（DTR→GPIO0、RTS→EN 一键下载）；板载 PWR红+TX黄+RX绿 3 颗 LED；**WS2812B-V6（GPIO48，5V 供 / 3.3V 数据直连免二极管）**；排针 H1/H2 沿用官方 J1/J3 顺序 1×22；ESP32-S3-WROOM-1 N16R8 模组（8MB PSRAM + 16MB Flash）。

### 3.1 分批焊接 + 每批上电判定

**批次 1 — 电源与接口（先焊这些，单独上电）**

焊：AMS1117-3.3（SOT-223：Pin1=GND、Pin2=VOUT、Pin3=VIN，散热片 Tab 连 VOUT）、输入/输出电容（输入 10µF 到地、输出 22µF 到地 + 100nF）、PWR 红 LED + 470Ω 限流、USB-C 座（串口那颗）、自恢复保险丝（若有）。

- [ ] **上电判定**：USB-C 接 5V（电脑/电源），万用表量 AMS1117 输出脚 = **3.30V ±0.1V**，PWR 红亮，**电流 < 30mA**。PASS 才继续。

**批次 2 — 串口与状态指示**

焊：CH343G + 其退耦 100nF、TX黄/RX绿 LED + 限流、若板载有晶振则一起焊。

- [ ] **上电判定**：电脑设备管理器/lsusb 出现 CH343 串口（或 `/dev/ttyCH343*`），插拔时有提示音；短接 TX-RX 自发自收能回环（可选）。

**批次 3 — 排针与 RGB**

焊：H1/H2 排针（对照官方 J1/J3 顺序 1×22，别错位）、WS2812B-V6（**DIN 方向、5V 供、GND 共地、DIN 串 330Ω 到 GPIO48**）。

- [ ] **上电判定**：3.3V 仍在，WS2812B 待程序点亮（先不亮正常）。

**批次 4 — 核心模组（最后焊！静电防护！）**

焊：ESP32-S3-WROOM-1 模组。先给模组底部所有焊盘薄涂焊锡/助焊剂，对齐丝印圆点（天线朝板边），拖焊或热风补焊，焊完用放大镜看四周无连锡。

- [ ] **焊完先不上电**，蜂鸣测：模组所有 3V3 脚之间通、3V3 与 GND 不短、相邻脚不桥、模组地脚与板地通。

### 3.2 关键元件方向核查

| 元件 | 方向/要点 | 翻车后果 |
|---|---|---|
| AMS1117-3.3 (SOT-223) | **Pin1=GND / Pin2=VOUT / Pin3=VIN**（左→右，字面朝自己；散热片 Tab 连 VOUT）；焊前用万用表二极管档确认 Tab 与 VOUT 通、与 VIN 不通 | 脚位焊反 → 3.3V 串到 5V/地，烧下游核心 |
| LED（红/黄/绿） | 长脚/切角=正极，经 470Ω 到 3.3V | 反接不亮（一般不烧，但排查费时） |
| USB-C 座 | CC1/CC2 按官方接 5.1k 下拉（或板载已拉），VBUS=5V、GND 共地 | CC 电阻错 → 电脑不供 5V / 不识别 |
| WS2812B-V6 | 认准丝印 **DIN（数据入）/ DOUT（数据出）** 脚位（方向以所购料规格书为准，别只凭切角猜）；VCC=5V、GND、DIN=GPIO48（串 330Ω） | 焊反 → 第一颗不亮且吃电流异常 |
| 排针 H1/H2 | 对照官方 J1/J3 1×22 顺序，1 脚丝印对齐 | 错位 → 扩展板/下载线全部对不上 |
| ESP32-S3 模组 | 圆点/天线标记对 PCB 丝印，模组下焊盘先上锡 | 偏位 → 引脚桥连，模组可能废 |

### 3.3 整板上电测试总顺序（模组焊完后）

1. [ ] USB 电流表接 5V，看待机电流 **< 150mA**（模组待机正常值，明显过大=短路）。
2. [ ] 万用表量各 3.3V 测试点 = 3.30V±0.1V。
3. [ ] 按住 BOOT（GPIO0 拉低）+ 点一下 EN 复位，进下载模式；电脑识别串口。
4. [ ] 烧录 `blink`（翻转一个 GPIO / 点 WS2812B）验证 MCU 活了。
5. [ ] 烧录 WiFi scan 例程，看能扫到热点 → 射频 OK。

## 4 STM32F407 核心板（VET6 LQFP-100 / 55×70mm，沉金）焊接 + 上电顺序

板子事实（已核对 BOM）：AMS1117-3.3（SOT-223，Pin1=GND/Pin2=VOUT/Pin3=VIN，Tab 连 VOUT）；8MHz 主晶振 + 32.768kHz RTC，负载电容 **20pF C0G（C16/C17）**；**VCAP(C5/C6)=2.2µF**（STM32 内部稳压器专用，ESP32 无此脚，两板不可混）；去耦(C1/C3/C7~C15)=100nF；LED1红PWR + LED2/LED3黄 + 470Ω；手工拖焊。

### 4.1 分批焊接 + 每批上电判定

**批次 1 — 电源与复位（先焊，单独上电）**

焊：AMS1117-3.3 + 输入/输出电容、**VCAP 2.2µF ×2（C5、C6，必须焊！）、PWR 红 LED + 470Ω、NRST 复位（10k 上拉到 3.3V + 100nF 到地 + 按键到地）**。

- [ ] **上电判定**：量 3.3V = **3.30V±0.1V**，PWR 红亮，**电流 < 30mA**。VCAP 脚对 GND 电压约 **1.2~1.3V**（内核稳压输出，正常）。

**批次 2 — 时钟**

焊：8MHz 主晶振 + 32.768kHz RTC 晶振，每颗晶振两端各焊一颗 **20pF C0G 负载电容**（C16/C17 等）。晶振尽量靠近 MCU、走线短、下方不走信号线。

- [ ] **上电判定**：3.3V 稳定不抖；无示波器可先跳过，靠后面点灯（用 HSE 外部晶振跑）验证起振。

**批次 3 — 调试口与状态**

焊：SWD（SWCLK/SWDIO/GND/3.3V）、UART 排针、H 排针、LED2/LED3 黄 + 470Ω、BOOT0（10k 下拉到地，想进 ISP 时拉高）。

- [ ] **上电判定**：3.3V 在；待焊 MCU 后 ST-LINK 能连。

**批次 4 — MCU（最后焊，LQFP-100 拖焊）**

焊：STM32F407VET6。先对齐 1 脚圆点、固定对角两 Pin、拖锡（多助焊剂）、吸锡带清桥、放大镜复查。

- [ ] **焊完先不上电**，蜂鸣测：VDD 各脚之间通、VSS 各脚之间通、VDD 与 VSS 不短、相邻脚不桥、BOOT0 下拉电阻到位。

### 4.2 关键元件方向核查

| 元件 | 方向/要点 | 翻车后果 |
|---|---|---|
| VCAP 2.2µF (C5/C6) | **必须焊**，陶瓷 X5R/X7R 或 C0G，靠近 VCAP 引脚到地 | 空着 → 内核电压不稳死机；短路 → 烧 |
| 晶振负载 20pF C0G (C16/C17) | 用 C0G/NP0，不能用 100nF 或错容值 | 错容值 → 不起振 / 频率偏 |
| 8MHz / 32.768kHz 晶振 | 无极性但封装要对，金属壳贴板、圆柱立式按丝印 | 虚焊 → 不起振，程序跑飞 |
| NRST 复位 | 10k 上拉到 3.3V + 100nF 到地 + 按键到地 | 被拉死 → MCU 一直复位不跑 |
| BOOT0 | 10k 下拉到地（从 Flash 启动）；想 ISP 拉高 | 悬空/拉高 → 不进用户程序 |
| LED | 470Ω 限流，长脚正 | 反接不亮 |
| STM32F407VET6 | 1 脚圆点对齐 PCB 圆点，别 180° 转反 | 转反 → 全板信号错乱，必重焊 |

### 4.3 整板上电测试总顺序（MCU 焊完后）

1. [ ] 限流电源接 5V，待机电流 **< 100mA**（焊完 MCU 正常待机值）。
2. [ ] 量 VDD = 3.30V±0.1V；量 VCAP ≈ 1.2~1.3V。
3. [ ] ST-LINK 接 SWD，开 STM32CubeProgrammer（或 Keil/Ozone），**能连上并读到芯片 ID（0x413 等）= 供电+焊接 OK**。
4. [ ] 烧录 blink（翻转 GPIO 接 LED2）验证起振+运行；改时钟树用 **HSE 外部 8MHz**（比内部 HSI 更准）。
5. [ ] 串口 printf 能出数据 → 调试口通。

> 底盘 F407Zx（LQFP-144，📋 未焊）：电源/晶振/VCAP 规则完全一致，引脚更多、桥连风险更高，蜂鸣测相邻脚要更细。

## 5 焊后通用短路自检（每块板焊完必做，上电前最后一关）

- [ ] 蜂鸣档：所有 **VCC 网络 vs GND 网络** 不短（电源入口 5V 焊盘除外，它本来就该有 5V 对地电容但非硬短）。
- [ ] 蜂鸣档：**5V 网络 vs 3.3V 网络** 不短（防止 LDO 反向、一上电烧核心）。
- [ ] 蜂鸣档：LQFP 100/144、模组底部、排针相邻脚 **抽样/逐对** 测，确认无桥连。
- [ ] 放大镜/手机微距看焊点：虚焊、连锡、锡珠（锡珠可能上电后飞溅短路）。
- [ ] 电源入口（USB / 5V 焊盘）单独测：确认 5V 不短到 3.3V、不短到 GND。

---

## 6 上电总流程（通用，逐条走）

1. [ ] 限流电源 / USB 电流表就位，先设限流 100mA。
2. [ ] **裸板上电**（不接任何外设：屏/麦/功放/CAN 都不接）。
3. [ ] 手摸 LDO / MCU / 模组：明显发烫立刻断电。
4. [ ] 量 3.3V 各测试点 = 3.30V±0.1V；GND 与外壳/地通畅。
5. [ ] 接 ST-LINK / 串口，烧录点灯程序。
6. [ ] 点灯成功 = 板子活了；再逐步接外设（屏→麦→功放→CAN），每接一个测一次。

## 7 黄金测试点 + 正常读数（先记这组数）

| 测试点 | 两块板都有？ | 正常读数 | 怎么测 |
|---|---|---|---|
| 5V 网络（USB-C VBUS / 5V 焊盘） | 都有 | **5.0V ±0.2V** | 黑笔接地，红笔点 5V 测试点 |
| 3.3V 网络（AMS1117 输出脚 / 任意 3.3V 测试点） | 都有 | **3.30V ±0.1V** | 黑笔接地，红笔点 3.3V 测试点 |
| GND（任意地过孔） | 都有 | **0V**（相对自身） | 通断档测与各 GND 相通 |
| VCAP（C5/C6 两端，对 GND） | 仅 STM32 | **≈1.2~1.3V** | 黑笔接地，红笔点 VCAP 焊盘 |
| EN（ESP32 模组使能脚） | 仅 ESP32 | **高电平 ≈3.3V**（上拉） | 量对 GND |
| NRST（STM32 复位脚） | 仅 STM32 | **高电平 ≈3.3V**（上拉） | 量对 GND；按复位键瞬间变 0 |
| BOOT0（STM32） | 仅 STM32 | **低电平 ≈0V**（下拉，从 Flash 启动） | 量对 GND；想 ISP 时人为拉高 |

## 8 上电异常速查（电压/电流 → 哪颗料）

### 8.1 3.3V 读数异常（最高频）

| 你量到的 3.3V | 危险 | 可能焊反/出问题的料 | 怎么确认 + 处理 |
|---|---|---|---|
| **= 0V（完全没输出）** | 【高危】 | ① AMS1117 输入脚(VIN)没吃到 5V → 输入脚焊反/连锡到别脚<br>② AMS1117 VOUT 对 GND 短路（输出电容 22µF/100nF 焊反击穿、下游 MCU/模组短路拉死、VOUT 与 GND 桥连）<br>③ 5V 网络本身没电（见 8.2） | 先量 5V 有没有：有 5V 但 3.3V=0 → 查 AMS1117 输入脚电压；输入脚有 5V 但输出 0 → 蜂鸣测 VOUT 对 GND 是否短（短路则查下游/电容）；输入脚无 5V → AMS1117 脚位错或 5V 没连到它。立刻断电再查，别硬上。 |
| **= 5V（等于输入）** | 【致命】 | AMS1117 **VOUT 与 VIN 脚位焊反/桥连**（最典型：芯片转了 180° 焊，或相邻脚连锡），输入直接串到输出 | **立刻断电！** 这会烧下游所有 3.3V 器件（MCU/模组/CH343G）。重焊 AMS1117，确认 Pin1=GND 在左、Tab 连 VOUT。焊前用二极管档确认 Tab 与 VOUT 通、与 VIN 不通（见 3.2 / 4.2）。 |
| **≈ 2.1V（偏低不到 3.3）** | 【高危】 | ① **量错点**：把 VCAP(≈1.2V) 或 晶振脚(≈1.6V) 当成 3.3V 量了（最常见！先排除）<br>② AMS1117 输入脚实际没 5V、被某处分压到 ~3.3V（5V 网络经电阻/连锡/漏电分压）→ dropout 不够，输出 = 输入−1.1V ≈ 2.2V<br>③ AMS1117 GND 脚虚焊/悬空 → 基准丢失，输出异常 | 先确认红笔点的确实是 3.3V 丝印测试点（不是 VCAP）。再量 AMS1117 输入脚电压：若输入只有 ~3.3V → 查 5V 网络为什么被拉低（上游/分压）；若输入有 5V 但输出 2.1V → AMS1117 地脚虚焊或芯片坏，补焊 GND 脚/换料。 |
| **= 4.xV（偏高但不满 5V）** | 【高危】 | AMS1117 部分脚位错（如 GND 脚虚焊导致稳压失效、pass-through 半导通） | 断电查 AMS1117 三脚 + Tab 方向，补焊地脚；仍异常换一颗。 |
| **抖动/纹波大/忽高忽低** | 【中】 | ① 输出电容没焊/虚焊/容值错（要求 ≥10µF，用 22µF 那颗）<br>② 输入电容缺失<br>③ 负载有短路被限流，电压被拉低 | 量输出电容两端是否 3.3V 且稳；补焊输出 22µF；确认输入 10µF 在位。 |

### 8.2 5V 读数异常

| 你量到的 5V | 危险 | 可能焊反/出问题的料 | 处理 |
|---|---|---|---|
| **= 0V（没供上）** | 【中】 | ① USB-C 座焊反/虚焊，VBUS 没连到 5V 网络<br>② CC1/CC2 下拉电阻(5.1k)没焊/错值 → 主机不给 VBUS（ESP32 板串口那颗 Type-C）<br>③ 自恢复保险丝断/没焊<br>④ 你插的线根本没供电 | 换根确认好的 USB 线/电源；量 USB-C 座 VBUS 焊盘有没有 5V；查 CC 电阻；跳过大保险丝试（仅排查，勿长期短接）。 |
| **< 5V（如 4.3V）带载更掉** | 【低】 | 供电线/座接触电阻大、线太细、电源带载差 | 换粗线/好电源；确认非板子问题（空载也低才是板子问题）。 |
| **= 5V 但 3.3V 异常** | — | 见 8.1 | 转 8.1 按 3.3V 值查。 |

### 8.3 VCAP（仅 STM32 板）异常

| 你量到的 VCAP | 危险 | 含义 | 处理 |
|---|---|---|---|
| **≈ 1.2~1.3V** | — | 正常，内核 1.2V 稳压输出 | 没问题，继续。 |
| **= 0V** | 【高危】 | C5/C6（2.2µF）**焊反/击穿短路到地**，或根本没焊（空着时内部稳压仍应有 ~1.2V，所以 0V 多半是短路） | 蜂鸣测 VCAP 对 GND 是否短；短路则查 C5/C6 方向/好坏、焊点桥连。VCAP 短路 → MCU 内核没电 → 必死机不启动。 |
| **= 3.3V** | 【致命】 | VCAP 电容焊反/桥连到 VDD(3.3V) → 内核过压，可能烧 MCU | **立刻断电**，重焊 C5/C6，确认一端接 VCAP 脚、另一端接 GND，不是接 3.3V。 |

### 8.4 上电电流异常

| 你看到的电流 | 危险 | 含义 | 处理 |
|---|---|---|---|
| **一上电直接爆表/限流触发（>100mA 且 3.3V 被拉低）** | 【致命】 | 某处**硬短路**：VCC-GND 桥连（LDO 输出区、模组底部、MCU 相邻脚、排针相邻脚）、极性电容反接、WS2812B 焊反 | 立刻断电！通断档蜂鸣测 3.3V 网络对 GND：哪段响就是哪段短。优先查 LQFP/模组底部连锡、电容反接。 |
| **电源区单独上电就 >30mA** | 【高危】 | 电源区本身短路：AMS1117 焊反、输出电容短路、LED 限流电阻没焊（LED 直接对地） | 先拔掉核心 IC，只留电源区查。 |
| **裸板待机 < 预期（如 ESP32 板 <5mA、STM32 板 <5mA）** | 【低】 | 可能某个本该通电的器件没供上（虚焊/漏焊），不一定是坏事，但要点灯才能确认活没活 | 继续走点灯流程验证。 |
| **待机正常但一跑程序电流不动/不增** | 【提示】 | MCU 可能没真跑（没进程序/没起振） | 查时钟/BOOT0/程序是否下载成功。 |

### 8.5 有电但不启动（核心活着但跑不起来）

**STM32（有 3.3V、VCAP≈1.2V，但 ST-LINK 连不上/不跑）：**
- [ ] **VCAP 没焊** → 内核不稳死机（最常见「有电不跑」）。
- [ ] **晶振没起振**：8MHz 两端负载电容(C16/C17)焊反/容值错(非 20pF C0G)/虚焊 → 用 HSE 跑不起来；万用表量晶振两脚约 1.6V 是常态偏置，≠起振，需示波器看正弦。
- [ ] **BOOT0 悬空/被拉高** → 不进 Flash 用户程序（应从 Flash 启动需 BOOT0=0，即 10k 下拉到地）。
- [ ] **NRST 被拉死**：10k 上拉/100nF 焊反、复位按键常闭 → MCU 一直复位。量 NRST 应是高，按按键瞬间变 0。
- [ ] **1 脚转反 180°** → 全板信号错乱，必重焊。
- [ ] **VDD/VSS 有漏脚没焊/桥连** → 部分电源域没电。

**ESP32（有 3.3V，但电脑不识别/不启动）：**
- [ ] **EN 没上拉** → 模组一直复位不运行（EN 应 ≈3.3V）。
- [ ] **GPIO0 下载时序/电路错**：CH343G 的 DTR→GPIO0、RTS→EN 一键下载电路（含三极管反相）焊错 → 进不了下载模式。
- [ ] **模组虚焊/底部连锡** → 部分电源/信号脚没通。
- [ ] **3.3V 到模组实际不足**（被压降） → 见 8.1 的 2.1V 排查。

## 9 外设专项（有电、核心活了，但外设不干活）

| 现象 | 优先查的料 | 提示 |
|---|---|---|
| WS2812B 第一颗就不亮 | DIN 脚位（以规格书为准，别凭切角）、5V 供、GND 共地、GPIO48 程序、330Ω 串没串 | 焊反 → 不亮且吃电流异常；共地没接 → 完全不响应 |
| 串口(CH343G)电脑不识别 | 驱动装没装、DTR/RTS 电路、USB-C CC 电阻 | 先换根线/换 USB 口排除电脑侧 |
| ST7789 屏不亮 | SPI 接线(CLK/MOSI/CS/DC/RST)、背光供电、3.3V 到没到、初始化程序 | 先确认 3.3V 和背光使能 |
| INMP441/MAX98357A 没声 | I2S 接线(SCK/WS/SD)、5V/3.3V 供电、程序初始化 | 用示波器/逻辑分析仪看 I2S 时钟有没有 |

## 10 反向速查：某颗料焊反了 → 表现是什么

| 如果焊反/焊错的是… | 上电量到的典型现象 | 一眼判断 |
|---|---|---|
| **AMS1117 转 180°（VIN/VOUT 反）** | 3.3V 网络 = 5V（或炸/烫） | 【致命】立刻断电，下游危 |
| **AMS1117 脚位错（GND 悬空等）** | 3.3V 偏高(4.x)或异常 | 重焊三脚+Tab |
| **LED 反接** | 不亮，一般不烧 | 翻过来重焊 |
| **极性电容(电解/钽)反接** | 漏液/发热/短路爆表 | 立刻断电换，反接会炸 |
| **USB-C 座反/虚焊** | 5V=0，板子没电 | 查 VBUS 焊点+CC 电阻 |
| **WS2812B 方向反** | 第一颗不亮、电流异常 | 翻 DIN/DOUT |
| **STM32 / ESP32 模组 1 脚转反** | 全板信号错乱、不启动、可能烫 | 必重焊对齐圆点 |
| **VCAP 电容(C5/C6)短路到地** | VCAP=0、MCU 死机不启动 | 查 C5/C6 |
| **VCAP 电容接到 3.3V** | VCAP=3.3V、可能烧内核 | 【致命】立刻断电 |

## 12 口诀

> 焊接：**分段焊、先电后压、核心最后、点灯才算活。**
> 排查：**3.3V=0→查输入/短路；3.3V=5V→AMS1117 反了快断电；3.3V=2.1V→先确认没量错 VCAP、再看 5V 有没有被分压；VCAP=0→C5/C6 短；VCAP=3.3V→C5/C6 接错快断电；电流爆表→某处硬短先断电源。** 一上电量一下，10 秒定位。
