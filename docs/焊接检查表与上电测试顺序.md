# 焊接检查表与上电测试顺序（防翻车版）

> 适用对象：① ESP32-S3-WROOM-1 N16R8 自研核心板（35.56×63mm）；② STM32F407VET6 核心板（LQFP-100，55×70mm）；③ 底盘 STM32F407Zx 核心板（LQFP-144）。
> 配套：硬件清单.md（BOM 已核对正确，无电容/RT9193 问题，回板可直接焊）。
> 核心原则：**先焊电源区 → 单独上电验证 3.3V → 再焊核心 IC（模组/MCU 最后焊）**，分段焊、分段测，烧也只烧便宜的 LDO，不烧几百块的核心。

---

## 〇、防翻车三条铁律（先看，焊之前念一遍）

1. **【静电】** 所有 CMOS 芯片（ESP32 模组、STM32、CH343G、WS2812B、MAX98357A、INMP441）都怕静电。焊前先摸一下接地的金属水管/机箱放电，最好戴防静电手环、烙铁接地。ESP32-S3 模组最贵最娇气，**最后焊、别用手直接捏引脚、别在干燥毛衣旁操作**。
2. **【分段】** 绝不一次焊完。每焊完"电源区"就先单独上电测 3.3V，PASS 了再焊下一区。核心模组/MCU 永远最后焊。
3. **【先电流后电压】** 上电前接 USB 电流表或限流电源（先限流 100mA）。先听/看有没有短路大电流、冒烟、烫手，再量电压。**一上电异常立刻断电**，别硬撑。

---

## 一、焊前准备（所有板子通用，勾完再开焊）

- [ ] 工具齐：电烙铁（建议 350℃ 以内尖头）、含松香芯焊锡（0.6~0.8mm）、助焊剂、吸锡带/吸锡器、镊子、放大镜或手机微距、万用表（蜂鸣档+电压档）。
- [ ] ESD 防护：防静电手环/接地、烙铁接地、工作台铺防静电垫或干净纸。
- [ ] 调试伙计备好：ST-LINK V2.1（STM32 用）、USB-TTL / CH343 驱动装好（ESP32 用）、USB 电流表或带限流的可调电源。
- [ ] BOM 分料：把每颗料按位号（R1/C2/U3…）摆好，对照 PCB 丝印图（不是封装图），别凭记忆拿料。
- [ ] 上板前先"通断体检"PCB：
  - [ ] 蜂鸣档测 **所有 GND 测试点应连通**（整板地是一张网）。
  - [ ] 蜂鸣档测 **任意 5V 网络 与 3.3V 网络 之间不短**（最怕 5V 灌进 3.3V 烧核心）。
  - [ ] 蜂鸣档测 **任意 VCC 与 GND 之间不短**（空板不应有电源-地短路）。
- [ ] 极性元件先认方向（焊前在桌上摆好，标好 1 脚/正极）：LED、电解/钽电容、USB-C、WS2812B、各芯片的圆点/切角/丝印 1 脚标记。

## 二、ESP32-S3 核心板（35.56×63mm）焊接 + 上电顺序

板子事实（已核对 BOM）：U2=**AMS1117-3.3** 供电，3.3V 去耦 22µF(C2)+10µF/100nF 多颗，符合乐鑫指南；**无 VCAP、无 RT9193**；CH343G（DTR→GPIO0、RTS→EN 一键下载）；板载 PWR红+TX黄+RX绿 3 颗 LED；**WS2812B-V6（GPIO48，5V 供 / 3.3V 数据直连免二极管）**；排针 H1/H2 沿用官方 J1/J3 顺序 1×22；ESP32-S3-WROOM-1 N16R8 模组（8MB PSRAM + 16MB Flash）。

### 分批焊接 + 每批上电判定

**批次 1 — 电源与接口（先焊这些，单独上电）**
焊：AMS1117-3.3（SOT-223：Pin1=GND、Pin2=VOUT、Pin3=VIN，散热片 Tab 连 VOUT）、输入/输出电容（输入 10µF 到地、输出 22µF 到地 + 100nF）、PWR 红 LED + 470Ω 限流、USB-C 座（串口那颗）、自恢复保险丝（若有）。
- [ ] **上电判定**：USB-C 接 5V（电脑/电源），万用表量 AMS1117 输出脚 = **3.30V ±0.1V**，PWR 红亮，**电流 < 30mA**。PASS 才继续。

**批次 2 — 串口与状态指示**
焊：CH343G + 其退耦 100nF、TX黄/RX绿 LED + 限流、若板载有晶振则一起焊。
- [ ] **上电判定**：电脑设备管理器/lsusb 出现 CH343 串口（或 /dev/ttyCH343*），插拔时有提示音；短接 TX-RX 自发自收能回环（可选）。

**批次 3 — 排针与 RGB**
焊：H1/H2 排针（对照官方 J1/J3 顺序 1×22，别错位）、WS2812B-V6（**DIN 方向、5V 供、GND 共地、DIN 串 330Ω 到 GPIO48**）。
- [ ] **上电判定**：3.3V 仍在，WS2812B 待程序点亮（先不亮正常）。

**批次 4 — 核心模组（最后焊！静电防护！）**
焊：ESP32-S3-WROOM-1 模组。先给模组底部所有焊盘薄涂焊锡/助焊剂，对齐丝印圆点（天线朝板边），拖焊或热风补焊，焊完用放大镜看四周无连锡。
- [ ] **焊完先不上电**，蜂鸣测：模组所有 3V3 脚之间通、3V3 与 GND 不短、相邻脚不桥、模组地脚与板地通。

### 关键元件方向核查（ESP32 板）

| 元件 | 方向/要点 | 翻车后果 |
|---|---|---|
| AMS1117-3.3 (SOT-223) | **Pin1=GND / Pin2=VOUT / Pin3=VIN**（左→右，字面朝自己；散热片 Tab 连 VOUT）；焊前用万用表二极管档确认 Tab 与 VOUT 通、与 VIN 不通 | 脚位焊反 → 3.3V 串到 5V/地，烧下游核心 |
| LED（红/黄/绿） | 长脚/切角=正极，经 470Ω 到 3.3V | 反接不亮（一般不烧，但排查费时） |
| USB-C 座 | CC1/CC2 按官方接 5.1k 下拉（或板载已拉），VBUS=5V、GND 共地 | CC 电阻错 → 电脑不供 5V / 不识别 |
| WS2812B-V6 | 认准丝印 **DIN（数据入）/ DOUT（数据出）** 脚位（方向以你买的料规格书为准，别只凭切角猜）；VCC=5V、GND、DIN=GPIO48（串 330Ω） | 焊反 → 第一颗不亮且吃电流异常 |
| 排针 H1/H2 | 对照官方 J1/J3 1×22 顺序，1 脚丝印对齐 | 错位 → 扩展板/下载线全部对不上 |
| ESP32-S3 模组 | 圆点/天线标记对 PCB 丝印，模组下焊盘先上锡 | 偏位 → 引脚桥连，模组可能废 |

### ESP32 板上电测试总顺序（模组焊完后）

1. [ ] USB 电流表接 5V，看待机电流 **< 150mA**（模组待机正常值，明显过大=短路）。
2. [ ] 万用表量各 3.3V 测试点 = 3.30V±0.1V。
3. [ ] 按住 BOOT（GPIO0 拉低）+ 点一下 EN 复位，进下载模式；电脑识别串口。
4. [ ] 烧录 `blink`（翻转一个 GPIO / 点 WS2812B）验证 MCU 活了。
5. [ ] 烧录 WiFi scan 例程，看能扫到热点 → 射频 OK。

## 三、STM32F407 核心板（VET6 LQFP-100 / 55×70mm，沉金）焊接 + 上电顺序

板子事实（已核对 BOM）：AMS1117-3.3（SOT-223，Pin1=GND/Pin2=VOUT/Pin3=VIN，Tab 连 VOUT）；8MHz 主晶振 + 32.768kHz RTC，负载电容 **20pF C0G（C16/C17）**；**VCAP(C5/C6)=2.2µF**（STM32 内部稳压器专用，ESP32 无此脚，两板不可混）；去耦(C1/C3/C7~C15)=100nF；LED1红PWR+LED2/LED3黄+470Ω；手工拖焊。

### 分批焊接 + 每批上电判定

**批次 1 — 电源与复位（先焊，单独上电）**
焊：AMS1117-3.3 + 输入/输出电容、**VCAP 2.2µF ×2（C5、C6，必须焊！）、PWR 红 LED + 470Ω、NRST 复位（10k 上拉到 3.3V + 100nF 到地 + 按键到地）**。
- [ ] **上电判定**：量 3.3V = **3.30V±0.1V**，PWR 红亮，**电流 < 30mA**。VCAP 脚对 GND 电压约 **1.2~1.3V**（内核稳压输出，正常）。

**批次 2 — 时钟**
焊：8MHz 主晶振 + 32.768kHz RTC 晶振，每颗晶振两端各焊一颗 **20pF C0G 负载电容**（C16/C17 等）。晶振尽量靠近 MCU、走线短、下方不走信号线。
- [ ] **上电判定**：3.3V 稳定不抖；无示波器可先跳过，靠后面点灯（用 HSE 外部晶振跑）验证起振。

**批次 3 — 调试口与状态**
焊：SWD（SWCLK/SWDIO/GND/3.3V）、UART 排针、H 排针、LED2/LED3 黄 + 470Ω、BOOT0（10k 下拉到地，想进 ISP 时拉高）。
- [ ] **上电判定**：3.3V 在；待焊 MCU 后 ST-LINK 能连。

**批次 4 — MCU（最后焊，LQFP-100 拖焊）**
焊：STM32F407VET6。先对齐 1 脚圆点、固定对角两 Pin、拖锡（多助焊剂）、吸锡带清桥、放大镜复查。
- [ ] **焊完先不上电**，蜂鸣测：VDD 各脚之间通、VSS 各脚之间通、VDD 与 VSS 不短、相邻脚不桥、BOOT0 下拉电阻到位。

### 关键元件方向核查（STM32 板）

| 元件 | 方向/要点 | 翻车后果 |
|---|---|---|
| VCAP 2.2µF (C5/C6) | **必须焊**，陶瓷 X5R/X7R 或 C0G，靠近 VCAP 引脚到地 | 空着 → 内核电压不稳死机；短路 → 烧 |
| 晶振负载 20pF C0G (C16/C17) | 用 C0G/NP0，不能用 100nF 或错容值 | 错容值 → 不起振 / 频率偏 |
| 8MHz / 32.768kHz 晶振 | 无极性但封装要对，金属壳贴板、圆柱立式按丝印 | 虚焊 → 不起振，程序跑飞 |
| NRST 复位 | 10k 上拉到 3.3V + 100nF 到地 + 按键到地 | 被拉死 → MCU 一直复位不跑 |
| BOOT0 | 10k 下拉到地（从 Flash 启动）；想 ISP 拉高 | 悬空/拉高 → 不进用户程序 |
| LED | 470Ω 限流，长脚正 | 反接不亮 |
| STM32F407VET6 | 1 脚圆点对齐 PCB 圆点，别 180° 转反 | 转反 → 全板信号错乱，必重焊 |

### STM32 板上电测试总顺序（MCU 焊完后）

1. [ ] 限流电源接 5V，待机电流 **< 100mA**（焊完 MCU 正常待机值）。
2. [ ] 量 VDD = 3.30V±0.1V；量 VCAP ≈ 1.2~1.3V。
3. [ ] ST-LINK 接 SWD，开 STM32CubeProgrammer（或 Keil/Ozone），**能连上并读到芯片 ID（0x413 等）= 供电+焊接 OK**。
4. [ ] 烧录 blink（翻转 GPIO 接 LED2）验证起振+运行；改时钟树用 **HSE 外部 8MHz**（比内部 HSI 更准）。
5. [ ] 串口 printf 能出数据 → 调试口通。

**底盘 F407Zx（LQFP-144）同法**，引脚更多、桥连风险更高，蜂鸣测相邻脚要更细；其余电源/晶振/VCAP 规则完全一致。

## 四、焊后通用短路自检（每块板焊完必做，上电前最后一关）

- [ ] 万用表蜂鸣档：所有 **VCC 网络 vs GND 网络** 不短（电源入口 5V 焊盘除外，它本来就该有 5V 对地电容但非硬短）。
- [ ] 蜂鸣档：**5V 网络 vs 3.3V 网络** 不短（防止 LDO 反向、一上电烧核心）。
- [ ] 蜂鸣档：LQFP 100/144、模组底部、排针相邻脚 **抽样/逐对** 测，确认无桥连。
- [ ] 放大镜/手机微距看焊点：虚焊、连锡、锡珠（锡珠可能上电后飞溅短路）。
- [ ] 电源入口（USB / 5V 焊盘）单独测：确认 5V 不短到 3.3V、不短到 GND。

## 五、上电总流程（通用，逐条走）

1. [ ] 限流电源 / USB 电流表就位，先设限流 100mA。
2. [ ] **裸板上电**（不接任何外设：屏/麦/功放/CAN 都不接）。
3. [ ] 手摸 LDO / MCU / 模组：明显发烫立刻断电。
4. [ ] 量 3.3V 各测试点 = 3.30V±0.1V；GND 与外壳/地通畅。
5. [ ] 接 ST-LINK / 串口，烧录点灯程序。
6. [ ] 点灯成功 = 板子活了；再逐步接外设（屏→麦→功放→CAN），每接一个测一次。

## 六、翻车应急（对着查）

- **一上电冒烟/烫手**：立刻拔电。闻味道定位（LDO 最常见），万用表二极管档测各路对地，找短路点；多半是电源区焊反/连锡。
- **3.3V 偏低或为 0**：查 LDO 输入有没有 5V、输出电容有没有短路、下游（MCU/模组）有没有短路拉低。
- **3.3V 偏高到 5V**：LDO 输出脚与输入脚焊反/桥连（AMS1117 脚位错，见第二节引脚顺序），会连带烧下游，**必须断电重焊**。
- **MCU 不运行（STM32）**：查 VCAP 有没有焊、晶振有没有、BOOT0 电平（应下拉）、NRST 有没有被拉死、VDD/VSS 有没有漏脚没焊。
- **模组不启动（ESP32）**：查 3.3V 到没到模组、EN 上拉、GPIO0 下载时序、Boot 模式。
- **串口不识别（CH343G）**：驱动装了没、DTR/RTS 电路对不对、USB-C CC 电阻对不对。
- **ST-LINK 连不上**：SWD 线序（SWCLK/SWDIO/GND/3.3V）、NRST 接没接、芯片有没有电、是不是 1 脚焊反。
- **WS2812B 第一颗就不亮**：查 DIN 脚位（以规格书为准）、5V 供、GND 共地、GPIO48 程序有没有初始化、330Ω 串没串。

## 七、逐项打勾总清单（打印照打）

### ESP32-S3 板
- [ ] 焊前：ESD 防护、BOM 分料、空板通断体检（GND 通、5V≠3.3V、VCC≠GND）
- [ ] 批次1 电源区 → 上电 3.3V=3.30V、PWR 亮、I<30mA
- [ ] 批次2 CH343G+LED → 串口识别
- [ ] 批次3 排针+WS2812B → 方向对、3.3V 在
- [ ] 批次4 模组 → 静电防护、蜂鸣测 3V3/GND/相邻不桥
- [ ] 上电：I<150mA、3.3V 正常、下载 blink 成功、WiFi scan 成功

### STM32F407 板（VET6 / Zx）
- [ ] 焊前：同上通断体检
- [ ] 批次1 电源+VCAP2.2µF+复位 → 3.3V=3.30V、VCAP≈1.2V、I<30mA
- [ ] 批次2 晶振+20pF C0G → 3.3V 稳
- [ ] 批次3 SWD/UART/排针/LED/BOOT0 → 3.3V 在
- [ ] 批次4 MCU → 1脚对齐、蜂鸣测 VDD/VSS/相邻不桥
- [ ] 上电：I<100mA、VDD=3.3V、ST-LINK 读到 ID、blink 成功、串口 printf 出数据

### 通用收尾
- [ ] 焊后短路自检全过（VCC≠GND、5V≠3.3V、无桥连、无锡珠）
- [ ] 裸板上电流程走完，点灯成功后才接外设
- [ ] 每接一个外设测一次，异常立刻断该外设

> 记住一句话：**分段焊、先电后压、核心最后、点灯才算活。** 按这个走，两块板基本不会翻车。
